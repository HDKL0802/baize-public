数据管理

关于

白泽 v0.10.15 —— 手机端是「白泽」的一个入口：底栏三个入口 = 对话（快捷方式）· 知识库 · 其他功能。知识库按 主要 / 资源 / 配置 三类收口：主要=待办 + 密码本，资源=附件 + 记忆，配置=API 服务（各模型站密钥）+ 频道 + 模型审批 + 语音。语音这一块：对话里每条回复都能点 朗读，输入栏那个 麦克风 是按住说话（松手出字、检查完再发）；音色、自动朗读、以及「真念一遍再听回来」的自检都在其他功能 → 配置 → 语音里。声音和听写都由后端那条独立的语音通道出（可以是阿里百炼的 qwen-tts + paraformer，也可以是任何 OpenAI 兼容的音频接口），手机上不留音频文件。连上白泽后端后，正本（待办 + 密码本 + 附件文件 + 记忆）全部落在 NAS 的知识库上：手机只留一份待办缓存和缩略图，密码与附件一律不在手机上留文件（打开附件时才临时取回，关掉就删）。记忆的语义搜索按「最低语义相似度」卡一道，不够相关的就不显示（并告诉你挡掉了几条），档位可在记忆页切换；记忆页还带「记忆树」（按天/周压出来的摘要，可手动重建）。对话里遇到要人工放行的危险操作（删除等），直接在气泡里放行或驳回，放行后白泽会接着把这次跑完——不用再跑去电脑。另提供 Go 版 CLI 供计算机侧使用。
