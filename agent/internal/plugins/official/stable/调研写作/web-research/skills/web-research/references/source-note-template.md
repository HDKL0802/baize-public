# 调研笔记模板

把这份骨架抄进 `note` 的 `content` 里，按题目删减。**来源那节不许省。**

```markdown
# <题目>

> 调研时间：<日期> ｜ 结论可信度：高 / 中 / 低（说明为什么）

## 结论（先说人话）

- 一句话结论。
- 如果结论有前提，把前提写出来（"在……的前提下"）。

## 依据

### 1. <要点小标题>

<两三句说清这个要点。>

- 来源：<标题> — <链接>

### 2. <要点小标题>

<……>

- 来源：<标题> — <链接>

## 分歧与不确定

- <哪两个来源对不上、分别怎么说。>
- <哪些地方资料不足、没法下结论 —— 如实写"没查到"，别补脑。>

## 相关

- [[相关笔记标题]]（把之前已经记过的相关笔记连上）
```

## 判断一段资料值不值得采信

| 信号 | 加分 | 减分 |
|---|---|---|
| 有原始出处（官方文档 / 论文 / 一手数据） | ✅ | |
| 说明了时间（什么时候的数据） | ✅ | |
| 只有一个来源、且是二次转述 | | ⚠️ |
| 通篇形容词没有具体数字 | | ⚠️ |
| 抓到的页面明显是营销 / 内容农场 | | ❌ 直接弃用 |
