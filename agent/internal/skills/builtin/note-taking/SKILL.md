# 笔记与星图

白泽有一套笔记系统（就是界面里的「记忆星图」），正本和长期记忆同一个库，
所以它也享受**语义检索与向量**——这正是"自动连边"的基础。

## 工具：`note`

| 想做的事 | action | 关键参数 |
|---|---|---|
| 写/覆盖一篇笔记 | `write` | `path` + `content`（同一 `path` 是**覆盖**） |
| 读一篇 | `get` | `key` |
| 列出 / 找笔记 | `list` | `query`（关键词）/ `tag` |
| 看出链与反向链接 | `links` | `key` |
| 看星图（点 + 边） | `graph` | `includeAuto`（是否带自动边，默认带） |
| 看标签云 | `tags` | — |
| 把相关笔记按语义连起来 | `autolink` | `topK` / `minSim` |
| 重解析悬空 `[[链接]]` | `resolve` | — |

删除某篇用 `note_forget`（**需要人工审批**）。

## 写法要点（直接决定星图连得好不好）

1. **显式双链**：正文里写 `[[另一篇的标题]]`，会被解析成关系。
   支持 `[[标题|显示别名]]`、`[[标题#小标题]]`。目标还不存在时算「悬空链接」，等它出现后可以用 `resolve` 接上。
2. **标签**：写 `#标签`（行首或空格之后）。井号后紧跟文字才算标签，所以 `# 一级标题` 不会被误判。
3. **标题**：不显式给 title 时，取正文第一个一级标题（`# 标题`）。
4. **自动连边**：写完之后可以跑一次 `autolink` —— 白泽按**向量语义相似度**把"其实在讲同一件事"的笔记自动连上，**不需要人手动去连**。
   - 前提是配了 embedding 通道；没配时 `autolink` 会明确说"连不了"，**不会假装连过**。
   - 跑到新笔记后想刷新关系，再跑一次即可（旧的自动边会被整体替换，手工 `[[双链]]` 不受影响）。

## 边界与习惯

- **笔记 vs 记忆**：成篇的、有结构的知识写成**笔记**；零散事实（"我的车牌是XX"）用 `memory` 工具。
- **先查再写**：新建前先 `list` 或 `graph` 看看有没有同类笔记 —— 有就补充它，没有才新建。**别造重复**。
- **一篇一个主题**：一篇笔记只讲一件事，关系靠 `[[双链]]` 连，而不是把什么塞进一篇。
- 导入整个 Obsidian 库由用户在桌面端「记忆星图 → 导入」里做（后端读不到用户电脑的磁盘）。
