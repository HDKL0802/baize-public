# 白泽桌面端 0.5.15

截图提问升级：框选完成后**原地弹出操作条**，照豆包电脑版做。

## 本版变化

- **截图操作条（照豆包）**
  - 框选完成**不再直接跳页面**：在**选区旁边原地**弹出一条操作条 —— **复制 / 提取文字 / 翻译 / 取消 / 问问白泽**。
  - **选区外自动压暗**（50% 棋盘格 XOR，突出选区），视觉对齐豆包。
  - **复制**：直接把选中的图写进系统剪贴板（`CF_DIB`），停在你原来的界面。
  - **取消**：点「取消」或按 `Esc`，不落盘、不跳转。
  - **提取文字 / 翻译**：自动打开「截图提问」页并跑出结果（中英双语，先译文后原文）。
  - **问问白泽**：把截图里的文字带进「对话」输入框，接着问。
  - 拖框后想重来：在操作条外再拖一次即可。
- **悬浮球右键菜单（照豆包排布）**：`打开白泽窗口` / `打开对话浮窗` / `截图提问` / `待审批（N）` / `退出`。
  - `打开对话浮窗` = 主窗口进「迷你小窗」（置顶、只留对话）。豆包那两项（隐藏 / 停用悬浮球）按你要求**不做**。
- **实现口径**：操作条、压暗、字体全部纯 Win32 GDI（`CreateFontW` / `DrawTextW` / `RoundRect` / `PatBlt(PATINVERT)`），**零新依赖**；每一步失败只记日志，不影响其它功能。

## 安装

1. 下载并运行 `baize-desktop-setup-0.5.15.exe`（用户级安装，不需要管理员）。
2. 已装过旧版：直接运行即可 —— 会自动认出来并按更新走，**安装位置可改**。

## 环境要求与说明

- **需要后端 0.9.28+**（`/api/agent/vision` 看图接口）。
- 抓屏 / 框选 / 剪贴板 / 小窗失败**只记日志、不影响启动**。日志在 `%APPDATA%\白泽\desktop.log`。
- **WebView2 运行时**：Windows 11 自带；部分 Windows 10 需先安装（装一次即可）。
- 二进制**未做代码签名**，Windows SmartScreen 可能提示 —— 点「更多信息 → 仍要运行」。
