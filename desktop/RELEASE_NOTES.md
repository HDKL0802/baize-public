# 白泽桌面端 0.5.6

插件市场：内置官方源 + 货架按「板块 · 阶段 · 分类」分组；官方插件仓上线。

## 本版变化

- **内置官方源**（0.5.5 起）：随白泽后端一起分发（离线可用），开箱有 **4 个官方插件**可装：
  - **联网调研**：给一个题目，联网查、抓正文、交叉核对，整理成**带来源**的笔记（需要先在配置里指定搜索通道）。
  - **跨端派活**：把任务派到你的电脑 / 手机执行，并如实带回回执；写清了只读档能用哪些动作、
    危险动作为什么要人工审批、以及"权限在设备侧判定，不是你批了就能删"。
  - **每日简报**：用定时任务每天定点汇总待办与关注点，写成**固定路径**的笔记（覆盖更新，不会攒出一堆）。
  - **星图整理**（测试版）：定期整理笔记星图 —— 补悬空双链、按语义连边、清重复（测试版：它会改你的笔记库，动手前会先问你）。
- **货架按板块分组显示**（新）：**官方**与**社区**两个板块，官方里再分**正式版 / 测试版**，板块内按**分类**排。
  每个插件都标出来源、版本、许可证与标签；测试版有醒目的「测试版」标记。
- **官方插件仓上线**：<https://github.com/HDKL0802/baize-plugins> —— 官方与社区的插件都在那一个仓里，
  想装最新版（不用升级桌面端）就在「插件源」里加它的 `index.json` 直链；社区投稿的流程也写在那仓的 README 里。

## 安装

1. 下载并运行 `baize-desktop-setup-0.5.6.exe`（用户级安装，不需要管理员）。
2. 已装过旧版：直接运行即可 —— 会自动认出来并按更新走，**安装位置可改**。

## 环境要求与说明

- **需要后端 0.9.22+**（板块/阶段/分类自 0.9.22 起；内置官方源 0.9.21 起；插件市场 0.9.20 起）。
- 官方插件里的「联网调研」要先在配置里指定搜索通道（`searxng` 或 `duckduckgo`），没配时它会**明确告诉你去哪儿配**，
  不会伪造搜索结果。
- 插件带 MCP 服务时，远端地址仍受后端 `allowRemote` 开关约束 —— 没放开会**如实告诉你没登记上**，不会静默跳过。
- **WebView2 运行时**：Windows 11 自带；部分 Windows 10 需先安装（装一次即可）。
- 二进制**未做代码签名**，Windows SmartScreen 可能提示 —— 点「更多信息 → 仍要运行」。
