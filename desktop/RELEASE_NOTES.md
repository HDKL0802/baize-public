# 白泽桌面端 0.5.22

控制台补齐一批「管理类」能力：设备删除 · 复制通道密钥 · 技能导入 · 插件升级 · 可观测性页 · 通道充值。

## 本版变化

- **设备页 · 删除设备**：每行多了「删除」——硬删设备表那一行，并把它在 `config.json` 里的备注一并清掉。
  （离线的设备记录会一直躺在表里，以前没有任何办法清掉。删除会二次确认。）
- **模型通道页 · 复制密钥 / 复制 URL**：每行多了两个动作，走新接口 `POST /api/agent/providers/secret`。
  ⚠️ 这是全项目**唯一**回显明文 Key 的接口 —— 控制台本身已在令牌闸门之后，用户要复制 Key 去别处粘贴；
  每次调用都会写一条 `Warn` 审计日志。复制优先用 `navigator.clipboard`，**局域网 http 下没有它，会自动回退**到
  临时 textarea + `execCommand`。
- **模型通道页 · 充值记账**：新增「充值」——填金额 + 备注即可记一笔；弹窗里能看到该通道的历史并逐条删除，
  行上显示「累计 ¥X」。**只记账，不做汇率 / 单价换算**（换算口径因通道而异，交给使用者自己算）。
- **技能页 · 分类与导入**：列表改成**按分类分组**（没有分类的归「未分类」），行上带分类标签；
  新增「导入 SKILL.md（粘贴）」——贴一份 SKILL.md 全文 + 目录名（可选分类）即可落盘，
  并支持一并带上 `references/` `templates/` `scripts/` 里的文本文件（`assets/` 二进制这轮不收）。
  表单里补了提示：**目录名（slug）与分类都只认 ASCII**（小写字母 / 数字 / `-._`），展示名才可中文。
- **插件市场 · 升级**：已安装行原来只有「有更新」标签，现在直接给「升级」按钮
  （后端新增 `action=update`，走同 id 覆盖升级）。
- **可观测性 · 按通道 / 模型**：模型通道明细表的表头改成「通道 · 模型」并显示 `model`。
  ⚠️ `model` 是**按当前配置**贴的标签：这些计数是**进程内、重启清零**的，所以只在「运行中途改过某通道模型」
  这种小窗口里会与历史数字不完全对应；要精确按 model 拆分得给 `llm.Provider` 加 `Model()`，本轮不做。
  表里另加了「累计充值」列，和 token 用量并排看。

## 验证

- `go build ./...` / `go vet` / `gofmt` / **`go test ./... -count=1` 全绿**；新增用例：设备删除、技能导入（带分类）、通道充值。
- 桌面端 8 个脚本（`apps*.js` / `shell.js`）逐一 `new Function(src)` 无头解析：全部 OK。
- 真接口逐个实测：删设备（幂等 200）、`providers/secret`（取回真值 + 非法 field 400）、技能 import（落盘 `skills/test-cat/smoke-skill/{SKILL.md,references/a.md}` + 列表带 category + 空名 / 二进制各回清晰 400）、充值（add / 负数 400 / remove / 列表）、可观测性（stat 里同时有 `provider` 与 `model`）。
- 控制台 `?ver=desktop` 无头真渲染：无 Uncaught / SyntaxError。
