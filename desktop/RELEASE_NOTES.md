# 白泽桌面端 0.5.11

新增「授权 / 审批弹窗」（B4）：危险操作执行前，置顶弹一个确认框等你放行。

## 本版变化

- **授权 / 审批弹窗（B4）**：只要有一条在等人工放行的危险操作，桌面端就**置顶弹一个确认框** ——
  不管当时在哪个应用里都会弹。框里给出：**操作描述 / 目标 / 参数 / 影响范围 / 建议 / 剩余时间**，
  以及「批准并执行」「拒绝」两个按钮。
  - 覆盖两类：**工具调用**（Agent 侧审批，可顺带「本会话不再问 / 永久放行」）与**跨端任务**（待放行的设备动作）。
  - **一次只处理一条**，其余排队显示「还有 N 条排队」；按到达时间先到先确认。
  - **超时按拒绝**：框里如实显示倒计时，超时由后端按「拒绝」处理并记录在案 —— 界面不替后端做决定。
  - 批准之前什么都不会发生；决定完立刻看下一条（每 4 秒轮询一次）。
- **频道类型收敛**：`qq`（QQ 官方机器人）与 `xiaoyi`（华为小艺）需要实名 / 华为开发者账号，
  按你的要求**「有源码但打不开」**：源码与单测都保留，但界面与接口都不再给入口、装配也不认。
  现在可选类型为：`webhook` / `onebot` / `feishu` / `dingtalk` / `yuanbao` / `wechat`。
- **模型通道 · Agnes AI**：按你给的端点补上两条模板 —— 国内 `https://api.agnes-ai.cn/v1`（正常走这条即可）、
  国际 `https://apihub.agnes-ai.com/v1`。

## 安装

1. 下载并运行 `baize-desktop-setup-0.5.11.exe`（用户级安装，不需要管理员）。
2. 已装过旧版：直接运行即可 —— 会自动认出来并按更新走，**安装位置可改**。

## 环境要求与说明

- **需要后端 0.9.27+**（频道类型收敛与 Agnes 模板自 0.9.27 起；审批弹窗依赖既有的 `/api/agent/approvals` 与 `/api/state`）。
- **WebView2 运行时**：Windows 11 自带；部分 Windows 10 需先安装（装一次即可）。
- 二进制**未做代码签名**，Windows SmartScreen 可能提示 —— 点「更多信息 → 仍要运行」。
