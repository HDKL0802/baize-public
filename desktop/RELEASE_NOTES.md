# 白泽桌面端 0.5.12

新增「桌面悬浮球」（B1）：常驻桌面右下角的轻量入口。同时带上 0.5.11 的「授权 / 审批弹窗」（B4）。

## 本版变化

- **悬浮球（B1）**：一个常驻桌面、置顶半透明的小圆球（纯 Win32 自绘，零新依赖）。
  - **拖动** = 移动；位置记到 `<数据目录>\ball.pos`，下次还在原地。
  - **单击** = 弹快捷菜单：`打开白泽` / `待审批（N）` / `退出`。
  - **双击** = 直接打开主窗口（多加的一个便利，不用先弹菜单）。
  - **球的颜色 = 状态**：天青=空闲、**黄（点变大）= 有待审批**、灰=连不上后端。每 10 秒问一次本机服务，如实反映。
- **授权 / 审批弹窗（B4）**（0.5.11 起）：危险操作执行前**置顶弹确认框**（任何应用界面里都会弹）——
  操作描述 / 目标 / 参数 / 影响范围 / 建议 / 剩余时间倒计时 + 「批准并执行」「拒绝」；
  工具调用可勾「本会话不再问 / 永久放行」；一次一条、其余排队；**超时按拒绝由后端处理**。
- **频道类型收敛**（0.5.11 起）：`qq`（要实名）与 `xiaoyi`（要华为开发者账号）**「有源码但打不开」** ——
  界面与接口都不给入口，源码与单测保留。现开放 6 种类型。
- **模型通道 · Agnes AI**（0.5.11 起）：按你给的端点补上两条模板 —— 国内 `https://api.agnes-ai.cn/v1`、国际 `https://apihub.agnes-ai.com/v1`。

## 安装

1. 下载并运行 `baize-desktop-setup-0.5.12.exe`（用户级安装，不需要管理员）。
2. 已装过旧版：直接运行即可 —— 会自动认出来并按更新走，**安装位置可改**。

## 环境要求与说明

- **需要后端 0.9.27+**。
- 悬浮球失败**只记日志、不影响启动**（拿不到句柄/建窗失败时其余功能照常）。日志在 `%APPDATA%\白泽\desktop.log`。
- **WebView2 运行时**：Windows 11 自带；部分 Windows 10 需先安装（装一次即可）。
- 二进制**未做代码签名**，Windows SmartScreen 可能提示 —— 点「更多信息 → 仍要运行」。
