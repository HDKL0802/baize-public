# 白泽桌面端 0.5.10

模型通道增强：从模板一键新建、成本与隐私标注、任务类型分流、回退通道、本地模型自动发现。

## 本版变化

- **从模板新建**：内置一批可核实的接入点模板（Ollama / LM Studio / vLLM / llama.cpp、DeepSeek、阿里百炼国内+国际、
  智谱 GLM、Moonshot、硅基流动、腾讯混元、OpenAI、Anthropic、OpenRouter、Gemini），选一个就自动填好地址与示例模型，
  并显示该模板的说明与文档链接。
- **模型发现**：填好 Base URL 后点「模型发现」，后端去读 OpenAI 兼容的 `/models`（Ollama 另读 `/api/tags`），
  把可用模型名列出来供挑选——不用手抄模型名。
- **成本与隐私标注**：每条通道可标「成本」（如 免费（本地）/ 按量计费）与「隐私」（如 本地，不出机器 / 公网云端）；
  不标隐私时按地址是否本机自动填。列表里一眼看到这条通道花不花钱、数据出不出机器。
- **任务类型分流 + 回退**：可给通道指定负责的任务类型（逗号分隔，空 = 通吃），或勾成「回退通道」（主通道失败时兜底）。
- ⚠️ **Agnes AI** 只作为「端点自行确认」的占位模板列入——公开资料显示它的接口**与 OpenAI 不完全兼容**，
  白泽不替它编造地址；请按其控制台页面自行填端点（必要时先做一层协议转换）。

## 安装

1. 下载并运行 `baize-desktop-setup-0.5.10.exe`（用户级安装，不需要管理员）。
2. 已装过旧版：直接运行即可 —— 会自动认出来并按更新走，**安装位置可改**。

## 环境要求与说明

- **需要后端 0.9.26+**（模型通道模板 / 发现 / 成本隐私标注自 0.9.26 起）。
- **WebView2 运行时**：Windows 11 自带；部分 Windows 10 需先安装（装一次即可）。
- 二进制**未做代码签名**，Windows SmartScreen 可能提示 —— 点「更多信息 → 仍要运行」。
