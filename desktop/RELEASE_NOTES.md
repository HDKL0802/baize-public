# 白泽桌面端 0.5.26

「电脑控制」的第 1 档落地：**电脑文件**页 —— 浏览这台电脑上的文件，挑几个一键**整理进知识库**。

## 本版变化

- **新增应用「电脑文件」**（左侧「核心」分组）：
  - 从「此电脑」（盘符列表）进去逐层浏览；顶部有「上一层 / 此电脑 / 刷新」。
  - 勾选若干文件 → **整理选中进知识库**（本机读文件 → 上传到 NAS 的知识库附件，到「知识库 → 附件」里看）。
  - 一次性显示权限档位与范围（如「权限：只读指定目录（D:\文档）」），一眼看得出现在能读哪儿。
- **权限闸门复用同一套**（与后端派活那条路完全一致）：能读到哪儿由「设置 → 桌面控制」的档位决定 ——
  - 档位 < 2（关闭 / 只读）**读不了文件**，界面会明确说「去哪儿放开」，不会静默失败；
  - 「只读指定目录 / 只读指定盘」只在圈定范围内可读，**越界目录一律拒绝并说清原因**；
  - 「完全访问」不再限范围。
- **新增本机接口**（只在本机回环，不经后端）：`GET /api/local/files/list`（列目录）、
  `GET /api/local/files/read`（读单个文件，回 base64；单文件上限 16MB）。
- **设备动作新增 `fs.list`**（后端 0.9.34）：白泽的智能体也能**列你电脑上的目录**（同样受设备侧权限闸门约束），
  这样它才能"看到你电脑上有什么文件"。控制台里它和 `fs.stat`/`fs.delete` 一样需要填 `paths`。

## 验证

- 桌面端 `go build` / `go vet` / `go test -count=1` 全绿；后端 `go build` / `go vet` / 相关包 `go test` 全绿。
- 新增桌面端单测：目录列举（**目录排前、按名字排序、带大小；不存在的目录如实报错**）、
  `permGate` 对 `fs.list` 的四档行为（关闭/只读**拒绝**、指定目录**圈内放行圈外拒绝**、完全访问放行、空路径报错）、
  MIME/Kind 推断（图片归 image）、盘根 `parentDir` 判定。
- 界面真渲染（桩掉网络 + 真 `apps8.js`）：
  `FILES roots=2 dirs=2 enterRows=4 boxes=2 perm="权限：dir-scoped（D:\tmp）" errs=0`
  —— 盘符列表 → 进入目录 → 文件带勾选框、目录没有，权限标签正确，零 JS 报错；
  9 个界面脚本 + `float.html` 内联脚本无头解析 `R n=10 clean`。

## 兼容与说明

- 后端同期升到 **0.9.34**（`fs.list` 动作进白名单）。手机端 **0.10.16 未改动**。
- 「电脑文件」用到的是**桌面控制权限**：默认档位是「关闭」，想用得先去「设置 → 桌面控制」升到第 2 档以上并圈定范围。
- 这一档**只读**：不写、不改、不删（删除仍是「完全访问」档 + 人工审批）。

## 安装

1. 下载并运行 `baize-desktop-setup-0.5.26.exe`（用户级安装，不需要管理员）。
2. 已装过旧版：直接运行即可 —— 会自动认出来并按更新走，**安装位置可改**。
