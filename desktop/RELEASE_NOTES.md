# 白泽桌面端 0.5.17

悬浮球与临时浮窗按反馈返工：球变回「圆」并靠边，浮窗修好关闭、靠边停放，主界面不再把截图塞进去。

## 本版变化

- **悬浮球**
  - **真·圆形**：之前是个 60×60 的**方块**（四个角露着底色），现在把窗口裁成圆（`SetWindowRgn` + 椭圆区域），
    球面直接画**界面图标**（`ui/icon.png` 双线性缩放后绘制）；取不到图标会退回一个渐变圆球。
  - **必须靠边**：拖动松手自动吸到离它**最近的那条屏幕边**；重启后也在边上（不再停在屏幕中间）。
  - **显示开关**：设置 →「常驻与自启」新增 **显示桌面悬浮球**。球丢了 / 被关掉了，勾回来即可。
    关掉时会顺手把全局快捷键 `Alt+Shift+S` 让出去，打开时再注册。
- **临时浮窗（独立进程）**
  - **修好「关闭」按钮**：之前点 ✕ 关不掉 —— 原因是 `DestroyWindow` 只能由**创建窗口的那个线程**调用，
    而关闭请求是从 HTTP 线程发过去的，等于没关。现在改成 `PostMessage(WM_CLOSE)` 交给窗口线程自己销毁。
  - **必须靠边**：浮窗默认贴在**屏幕右边**垂直居中；拖动松手后自动吸到最近的那条边（和悬浮球一个规矩）。
  - **每个模式只干一件事**：对话 / 提取文字 / 翻译 各自独立进程、独立界面；去掉了挤在一起的大图预览，
    操作收进底部一条（重试 · 复制），翻译才显示语言选择。
  - **「问问白泽」**：不再跳主界面，改为唤起**对话浮窗**并把截图里的文字读出来预填进输入框，接着问就行。
- **主界面**
  - **移除「截图提问」应用**：截图/提取/翻译都不再是主界面里的一个「页」。对话是对话、截图是截图，彻底分开。
    截图仍然走 **`Alt+Shift+S`**、悬浮球右键「截图提问」。
  - 圆角整体收敛（浮窗元素 4–5px），不再动辄大圆角。
- **截图**：点「取消」或按 `Esc` **什么都不留**（不落盘、不跳页），只有点「保存」才弹系统「另存为」。

## 兼容与说明

- **需要后端 0.9.28+**（`/api/agent/vision` 看图接口）。
- 浮窗看图的账号身份沿用桌面端已保存的配对令牌；多用户「登录会话」暂不带到浮窗（浮窗与主界面不同源）。
- 抓屏 / 框选 / 剪贴板 / 浮窗失败**只记日志、不影响主程序启动**。日志在 `%APPDATA%\白泽\desktop.log`。
- **WebView2 运行时**：Windows 11 自带；部分 Windows 10 需先安装（装一次即可）。

## 安装

1. 下载并运行 `baize-desktop-setup-0.5.17.exe`（用户级安装，不需要管理员）。
2. 已装过旧版：直接运行即可 —— 会自动认出来并按更新走，**安装位置可改**。
