# 白泽桌面端 0.5.3

多用户与协作：账号各自独立、组内共享文档、冲突左右对照协商。

## 本版变化

- **「账号与共享」（新）**：四个页签 —— 身份 / 用户 / 用户组 / 共享文档。
  - **登录**后，你看到和写入的**记忆库、笔记、知识库都是你自己那一份**（后端按账号分区，天然隔离）；
    没登录时用的仍是本机默认库 —— 单人用法完全不变。
  - **用户管理**：新建 / 删除 / 改口令（改口令会作废该用户的旧登录）。删除用户**不会删掉数据目录**（删数据不可逆，留给你自己决定）。
  - **用户组**：建组、加人/移人。组里成员共享一份「共享库」。
  - **共享文档**：上传 / 列表 / 下载 / 删除。**谁上传，组内其他成员刷新就能看到并下载**。
- **「冲突协商」（新）**：同一份文档被两人各改了一版 → 后端**自动开一次协商**。
  - **左右对照、都只能看**：界面里没有任何"改对方那版"的操作（后端也没有这样的接口）。
  - **聊天**把话说清；会话 id 就是"聊天链接"（挂在用户组路径下的深链）。
  - 收场两条路：**保留某一版**，或**一方放弃自己那版**（对方的版本自动成为正本）。定稿后同名其余版本会被清掉。
  - **音视频**：检测到麦克风/摄像头就能发起 WebRTC 通话（同一局域网内直连，后端只中转信令、不碰媒体）；
    没有设备或未授权，就用上面的打字框 —— 后端两种一视同仁，由客户端决定。
- **安全**：登录会话令牌只经本机代理以 `X-Baize-Session` 头透传给后端；**配对令牌始终由本机代理添加，网页接触不到**。

## 安装

1. 下载并运行 `baize-desktop-setup-0.5.3.exe`（用户级安装，不需要管理员）。
2. 已装过旧版：直接运行即可 —— 会自动认出来并按更新走，**安装位置可改**。

## 环境要求与说明

- **需要后端 0.9.19+**（账号自 0.9.18 起、冲突协商自 0.9.19 起）。
- 后端**首次启动**会自动建一个 `admin` 账号，随机口令在 NAS 数据目录的 `admin-password.txt` 里；登录后请尽快改掉。
- 只有**组内成员**能看该组的共享文档与协商；非成员/未登录一律 403。
- **WebView2 运行时**：Windows 11 自带；部分 Windows 10 需先安装（装一次即可）。
- 二进制**未做代码签名**，Windows SmartScreen 可能提示 —— 点「更多信息 → 仍要运行」。
