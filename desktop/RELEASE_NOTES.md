# 白泽桌面端 0.5.19

悬浮球返工（真圆 / 变小 / 去掉挡视线的东西）+ 临时浮窗可拖动、开窗不再跳位 + 亮色/暗色/跟随系统主题。

## 本版变化

- **悬浮球**
  - **真·圆（抗锯齿）**：之前是 `SetWindowRgn` **硬边**裁圆，一圈全是台阶（你说的"一大堆方块"）。
    现在改成**逐像素 alpha**（`UpdateLayeredWindow` + 手写圆形遮罩，边缘 1px 线性过渡）—— 圆边是真的平滑。
  - **去掉中心的圆点**：球面只留白泽图标，不再像"叼着个球"。
  - **变小**：直径 60px → **40px**（约两三个鼠标箭头大）。
  - **圆外点击穿透**：`WM_NCHITTEST` 对圆外的点返回 `HTTRANSPARENT`，方角不再挡住底下的窗口。
- **截图光标**：改回**十字**。之前把 `IDC_CROSS` 写成了 `32514`，而那是 `IDC_WAIT` —— 所以整段截图过程鼠标一直在转圈。
- **临时浮窗**
  - **删掉底部那条**「正在处理 / 重试 / 复制」——结果区直接占满整屏，不再臃肿；翻译的语言切换挪到标题栏（「中 / EN」）。
  - **图钉换图标 + 用姿态表状态**：不再是图钉 emoji；**未钉住时图钉斜着、钉住时竖直**（不再靠变色）。
  - **窗口能拖了**：按住标题栏拖动，松手自动吸到最近的屏幕边。
    （之前拖不动是因为 WebView2 的客户区是**子窗口**，鼠标命中测试被它接管，顶层窗口收不到 `WM_NCHITTEST` —— 只能走「JS 按住 → 原生 `SetWindowPos`」。）
  - **打开不再跳位**：之前会先在默认位置闪出一个白框、再挪到右边。现在用**线程级 CBT 钩子**在窗口真正创建前就改好 `CREATESTRUCT` 的位置与样式（无边框/置顶/不进任务栏），一步到位。
- **主题：亮色 / 暗色 / 跟随系统**（设置 →「外观」）
  - 配色口径借 **QwenPaw** 的中性表面阶（surface / surface-2 / border / 三档字色），主色仍是白泽自己的天青 —— 中性底 + 一个彩色点缀。
  - 「跟随系统」跟 Windows 的浅色/深色走；选择记在本地配置，**控制台与临时浮窗同一主题**。

## 兼容与说明

- **需要后端 0.9.28+**（`/api/agent/vision` 看图接口）。
- 本轮**只动桌面端**（含 `shell.css` 配色层 + `float.html`），后端与手机端无改动。
- 手机端的亮/暗主题在下一批（手机端目前只有暗色）。

## 安装

1. 下载并运行 `baize-desktop-setup-0.5.19.exe`（用户级安装，不需要管理员）。
2. 已装过旧版：直接运行即可 —— 会自动认出来并按更新走，**安装位置可改**。
