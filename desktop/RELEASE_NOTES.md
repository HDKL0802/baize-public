# 白泽桌面端 0.5.16

临时浮窗重做：**一个窗口一个进程**（照豆包那套 Chromium 多进程模型），截图流程也一并收尾。

## 本版变化

- **临时浮窗改成独立进程**（照豆包）
  - 「提取文字 / 翻译 / 对话浮窗」不再挤在主进程里：主进程用同一个 exe 带 `-float=<模式>` 再起一个进程，
    子进程自己建一块 WebView2、跑自己的消息循环（任务管理器里会看到多一个白泽进程，这是有意为之）。
  - 为什么必须这样：桌面端用的 WebView2 绑定把整包绑死在主线程，同进程再开第二块会踩 COM 单线程 /
    消息循环 / `WM_QUIT` 的坑（关浮窗＝整个应用退出）。多进程天然隔离。
  - 浮窗形态：**无边框 + 置顶 + 不进任务栏**；顶部标题栏可拖动；点 **📌 钉住** 后锁死位置不可拖。
    点 ✕ 关闭（只关这个浮窗，不影响主程序）。
  - **同模式只开一个**：再次触发时把新截图直接推给已开的那个浮窗并置顶，不重复开窗、也不用等它重新初始化。
  - 每种模式一个固定 WebView2 用户目录（复用它开得快，也不会攒磁盘）。
- **截图流程收尾**
  - **不再自动保存**：截图只在内存里，只有点「保存」才弹系统「另存为」由你选位置。
  - 操作条新增 **保存** 按钮（复制 / 保存 / 提取文字 / 翻译 / 取消 / 问问白泽）。
  - **修**：一个进程里只能截一次（截图窗口类第二次注册报 `Class already exists`，之后再也截不出来）。
  - 框选改为**脏区重画**，拖动更跟手（不再每帧重画整屏）。
  - **全局快捷键 `Alt+Shift+S`** = 截图提问。
  - 「截图提问」从左侧导航里**隐藏**（它本来就是快捷键 / 悬浮球唤起的临时功能）。
- **悬浮球**
  - **单击** = 唤起「对话浮窗」（独立小窗，不再把主窗口缩成迷你窗）；双击仍打开完整窗口。
  - 右键菜单「打开对话浮窗」同效。
- **托盘**：从托盘唤出时一律回到「工作模式」的完整窗口（不再停在迷你小窗里）。
- **设置**：新增「自动更新」开关 + 检查间隔（后台定时检查，有新版自动下载并重启）；删除「关于」页。

## 兼容与说明

- **需要后端 0.9.28+**（`/api/agent/vision` 看图接口）。
- 浮窗看图的账号身份沿用桌面端已保存的配对令牌；多用户「登录会话」暂不带到浮窗（浮窗与主界面不同源）。
- 抓屏 / 框选 / 剪贴板 / 浮窗失败**只记日志、不影响主程序启动**。日志在 `%APPDATA%\白泽\desktop.log`。
- **WebView2 运行时**：Windows 11 自带；部分 Windows 10 需先安装（装一次即可）。

## 安装

1. 下载并运行 `baize-desktop-setup-0.5.16.exe`（用户级安装，不需要管理员）。
2. 已装过旧版：直接运行即可 —— 会自动认出来并按更新走，**安装位置可改**。
