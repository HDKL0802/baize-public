# 白泽桌面端 0.5.13

新增「截图提问」：拖框选中屏幕上一块，回来**复制 / 提取文字 / 翻译**。入口在悬浮球右键菜单与侧边栏「系统」组。

## 本版变化

- **截图提问（B1 · 截图）**
  - **入口**：悬浮球右键菜单新增「截图提问」（排在「打开白泽」之后）；侧边栏「系统」组新增「截图提问」应用。
  - **抓屏 + 框选**：抓**整个虚拟屏**（多显示器也算上）→ 覆盖全屏的置顶层上拖出一个选框 → 松开即裁剪；**Esc 取消**；选区过小按误触当全屏。
  - **三件事**：
    - **复制** —— 把截图以 `CF_DIB` 放进系统剪贴板，可直接粘到别处。
    - **提取文字** —— 交给多模态模型，把图里文字原样抠出来（看不清的用 □ 代替）。
    - **翻译** —— 中英双语，先给译文、再在下一行给原文（原文语言与目标一致则只给译文）。
  - **看图模型**：优先选 `kinds` 含 **`vision`** 的模型通道；否则用第一条可用通道。模型不支持图片时，接口会把原话抛出来，**不假装识别成功**。建议配 `qwen-vl-max` / `gpt-4o` / `claude-3-5-sonnet` 这类多模态模型。
  - **落盘**：`<数据目录>\shot-latest.png`（另留一份带时间戳的 `shot-<时间>.png`），界面用 `?t=<时间戳>` 破缓存显示原图。
- **实现口径**：抓屏（`GetDC` + `BitBlt` + `GetDIBits`）、框选覆盖层、剪贴板（`GlobalAlloc` + `RtlMoveMemory` + `SetClipboardData`）**全部纯 Win32 syscall，零新依赖**；每一步失败只记日志，不影响其它功能。界面走本机回环服务 `/api/local/shot/*`，看图走后端 `/api/agent/vision`（令牌不进网页）。

## 安装

1. 下载并运行 `baize-desktop-setup-0.5.13.exe`（用户级安装，不需要管理员）。
2. 已装过旧版：直接运行即可 —— 会自动认出来并按更新走，**安装位置可改**。

## 环境要求与说明

- **需要后端 0.9.28+**（`/api/agent/vision` 看图接口）。
- 悬浮球 / 截图失败**只记日志、不影响启动**（拿不到句柄/建窗失败时其余功能照常）。日志在 `%APPDATA%\白泽\desktop.log`。
- **WebView2 运行时**：Windows 11 自带；部分 Windows 10 需先安装（装一次即可）。
- 二进制**未做代码签名**，Windows SmartScreen 可能提示 —— 点「更多信息 → 仍要运行」。
