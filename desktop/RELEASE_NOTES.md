# 白泽桌面端 0.5.9

新增「频道」：你和白泽在「哪里」对话 —— 现在桌面端也能配置与测试。

## 本版变化

- **「频道」（新应用，能力分组）**：与后端控制台对齐的四件事 —— 列出 / 增删改 / 启停 / **测试发送**。
- **支持 8 种频道类型**，表单会按类型只显示该填的字段：
  - `webhook`（出站 POST 到一个 URL）、`onebot`（QQ OneBot V11 反向 WS）
  - `feishu`（飞书）、`dingtalk`（钉钉 Stream 长连接，免公网）
  - `qq`（QQ 官方机器人）、`xiaoyi`（华为小艺，AK/SK + Agent ID）
  - `yuanbao`（腾讯元宝）、`wechat`（个人微信，官方 iLink Bot 扫码登录）
- **密钥 / 令牌一律「留空 = 不改」**，界面只显示"有没有"，不回显明文；appId / agentId / domain 这类非敏感项可回填编辑。
- 每个类型下方都写了**怎么接、填什么、能不能收**的说明，避免"配了以为能收、其实收不到"。

## 安装

1. 下载并运行 `baize-desktop-setup-0.5.9.exe`（用户级安装，不需要管理员）。
2. 已装过旧版：直接运行即可 —— 会自动认出来并按更新走，**安装位置可改**。

## 环境要求与说明

- **需要后端 0.9.25+**（频道新增 钉钉 / QQ 官方 / 小艺 / 元宝 / 微信 适配器）。
- 「个人微信」首次需**扫码登录**：二维码会写进后端日志（登录后凭证落盘，之后自动收发）。
- 说明：钉钉 / 飞书 / OneBot 可离线自测；QQ 官方 / 小艺 / 元宝 / 微信 的**真实收发**需要在有账号的环境验证，白泽这边把协议实现到位，但没人能替你登录。
- **WebView2 运行时**：Windows 11 自带；部分 Windows 10 需先安装（装一次即可）。
- 二进制**未做代码签名**，Windows SmartScreen 可能提示 —— 点「更多信息 → 仍要运行」。
