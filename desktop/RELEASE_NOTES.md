# 白泽桌面端 0.5.8

新增「外部 Agent」：把一段独立的活委托给别的 Agent 去干，只把结论拿回来。

## 本版变化

- **「外部 Agent」（新应用，能力分组）**：
  - 配置一组外部 Agent（像模型通道一样增删改）：id / 显示名 / 类型 / 地址 / 令牌 / 说明 / 超时 / 启停。
  - 两种类型：`http`（任意 HTTP 端点，OpenAI 兼容的 agent 或别的编排服务）、
    `baize`（另一个白泽实例，喂它的 /api/agent/run + 配对令牌，复用同一套协议）。
  - **探活**：用一句极小的任务真跑一次，如实回报耗时与回文。
  - **手动委托**：你（人）点下去的委托，直接派；而 **Agent 自主委托**走工具 `agent_call`，
    属危险操作，会进审批队列等人放行。
  - **最近委托记录**：派给谁、任务、结果、耗时、出错。只留最近 50 条，**本次启动以来**（重启即清零）——
    完整轨迹在运行记录里，这里看的是"刚才派过什么"。
- **安全口径（务必照做）**：外部 Agent 一律当**不可信执行体** —— 只传任务文本，
  **别在委托里放本机文件 / 密钥**；回来的内容按外部输入处理。地址不是本机时，
  要在表单里显式勾选「地址不是本机（需要放行远端）」，否则会被本地优先策略挡下。
- **可观测性接上**：「可观测性」页新增外部 Agent 的**按目标统计**（次数 / 失败 / 平均耗时 / 最近出错）；
  健康检查里也多一项「外部 Agent」（配了却没填地址 = error）。

## 安装

1. 下载并运行 `baize-desktop-setup-0.5.8.exe`（用户级安装，不需要管理员）。
2. 已装过旧版：直接运行即可 —— 会自动认出来并按更新走，**安装位置可改**。

## 环境要求与说明

- **需要后端 0.9.24+**（外部 Agent 自 0.9.24 起；可观测性 0.9.23 起）。
- **WebView2 运行时**：Windows 11 自带；部分 Windows 10 需先安装（装一次即可）。
- 二进制**未做代码签名**，Windows SmartScreen 可能提示 —— 点「更多信息 → 仍要运行」。
