# 白泽桌面端 0.5.2

桌面控制分权限、安装/更新更顺手、数据目录可改。

## 本版变化

- **桌面控制（新）· 五档权限**：智能体能对这台电脑做什么，由你在「设置 → 桌面控制」里决定。
  | 档位 | 允许什么 |
  |---|---|
  | 关闭 | 什么都不能做（连读都不行），只剩探活心跳 |
  | 只读 | 只能读本机信息与当前前台窗口 |
  | 只读指定目录 | 只在你自己圈定的目录里读文件信息 |
  | 只读指定盘 | 在你勾选的整个盘里读（高风险） |
  | 完全访问 | 不限定范围；删除等危险动作仍会先弹人工审批（高风险） |
  - 这是**设备侧真正的闸门**：权限不够的能力本机根本不上报，后端也就派不过来。
  - 选「只读指定盘 / 完全访问」需先确认**风险免责声明**；**首次进入也会弹一次**。
  - 改权限后设备自动重连，能力立刻更新。
- **数据目录可改**：桌面端的配置与日志不再固定放 C 盘，可在「设置 → 数据目录」改到 D 盘或任意文件夹，
  改完立即把配置搬过去（日志下次启动起在新位置）。
- **安装器修复**：
  - **自动识别已安装**（多路探测：自身记录 / 卸载信息 / 默认位置 / 常见盘符），认出就走更新，不再像"重新安装一遍"。
  - **目录页始终显示**：更新时默认沿用原目录，但**可以改到别的盘**（旧版更新时跳过选目录页，等于只能装在原盘）。
  - 全新安装仍有**风险与免责声明**欢迎页（最高两档的后果自负）。
- 免责声明同时写进了仓库 `README.md`（GitHub 页面可见）。

## 安装

1. 下载并运行 `baize-desktop-setup-0.5.2.exe`（用户级安装，不需要管理员）。
2. 已装过旧版：直接运行即可 —— 会自动认出来并按更新走，安装位置可改。

## 环境要求与说明

- **建议后端 0.9.15+**（记忆星图接口自 0.9.15 起才有）。
- **WebView2 运行时**：Windows 11 自带；部分 Windows 10 需先安装（装一次即可）。
- 二进制**未做代码签名**，Windows SmartScreen 可能提示 —— 点「更多信息 → 仍要运行」。
