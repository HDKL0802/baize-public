# 白泽桌面端 0.5.0

安装包改为**多文件**形态，并修好安装/更新体验。

## 本版变化

- **界面不再内嵌进 exe**：安装后是 `baize-desktop.exe` + `ui/` 目录（多个文件），更像常规应用；不再是一个单文件。
- **安装器 · 更新模式**：检测到已装过时，跳过「欢迎 / 选目录」页，直接原地更新到原目录，不再看起来像「重新安装」。
- **安装器 · 安装路径**：全新安装时优先装到非系统盘（存在 D/E/F 就装过去），不再默认塞进 C 盘；想装哪儿仍可在向导里改。
- **修复覆盖失败**：白泽在托盘运行时安装，旧 exe 被占用会导致覆盖失败（装了却还是旧版）——现在安装前先结束进程并等待其释放文件。
- **自动更新随形态升级**：更新包改为 `zip`（含 exe + ui/），校验 sha256 后整体替换 exe 与界面。

## 安装

1. 下载并运行 `baize-desktop-setup-0.5.0.exe`（用户级安装，不需要管理员）。
2. 若已装过旧版：直接运行即可，会走更新模式装回原目录。

> ⚠️ **从 0.4.1 及更早升级**：由于程序从「单文件」改为「exe + ui/ 多文件」，**请用本安装包手动安装一次**；这一步之后的自动更新才走新的 zip 更新包。

## 环境要求与说明

- **建议后端 0.9.12+**（人设接口自 0.9.2 起就有）。
- **WebView2 运行时**：Windows 11 自带；部分 Windows 10 需先安装（装一次即可）。
- 二进制**未做代码签名**，Windows SmartScreen 可能提示 —— 点「更多信息 → 仍要运行」。
