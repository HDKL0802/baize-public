# 白泽桌面端 0.5.1

「记忆」升级为**记忆星图**：融合笔记系统 + 自动双向链接 + 图谱可视化。

## 本版变化

- **记忆星图（新）**：桌面端「记忆」应用改成四个页签 —— 检索 / 星图 / 笔记 / 导入。
  - **星图**：力导向图谱（纯 canvas，无外部依赖）。实线 = 手工双链，虚线 = 自动连边；
    支持滚轮缩放、拖拽节点/画布、单击选中、双击打开笔记、「只看选中」看局部图。
  - **笔记**：Markdown 正本 + 编辑器；正文里的 `[[双向链接]]` 与 `#标签` 会被自动解析，
    右侧实时显示**出链**与**反向链接**（含自动边的相似度）。
  - **自动连边**：按向量语义相似度把「其实在讲同一件事」的笔记自动连起来（不需要手写双链）。
  - **导入**：直接扫描**本机文件夹**里的 `.md`（Obsidian 库）导入后端；
    后端在 NAS 上读不到你的磁盘，所以扫描这一步由桌面端完成。
- 后端新增「笔记 / 星图」接口（`/api/agent/notes*`）与 Agent 工具 `note` / `note_forget`；
  桌面端新增本机导入接口 `/api/local/notes/import`。

## 说明

- 自动连边需要配好 **embedding 通道**；没配时不会假装连过，会明确提示先配通道。
- 笔记与记忆共用同一套语义检索与向量，所以笔记的自动连边和记忆检索走的是同一份向量。

## 安装

1. 下载并运行 `baize-desktop-setup-0.5.1.exe`（用户级安装，不需要管理员）。
2. 若已装过旧版：直接运行即可，会走更新模式装回原目录。

## 环境要求与说明

- **建议后端 0.9.15+**（记忆星图接口自 0.9.15 起才有）。
- **WebView2 运行时**：Windows 11 自带；部分 Windows 10 需先安装（装一次即可）。
- 二进制**未做代码签名**，Windows SmartScreen 可能提示 —— 点「更多信息 → 仍要运行」。
