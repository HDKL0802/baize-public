# 白泽桌面端 0.5.7

新增「可观测性」：白泽最近干得怎么样，一屏看完。

## 本版变化

- **「可观测性」（新应用，系统分组）**：顶上选时间窗（近 1 小时 / 近 24 小时 / 近 7 天 / 近 30 天 / 全部），
  下面一次给全：
  - **KPI**：运行次数（含失败）· 平均 / P95 / 最长耗时 · token（入/出）· 工具调用与重试 · 日志里的错误与警告数；
  - **健康（先看这里）**：模型通道、向量化通道、向量补全、MCP 服务、频道、定时任务、待审批、
    搜索通道、命令白名单、记忆库、知识库。**红=配了但用不了（真问题）、琥珀=没配（带一句该去哪儿配）、
    绿=本来就该这样** —— 宁可显示"没配"，也不用一个绿灯盖过去；
  - **运行量**：一根柱子一个时间桶，桶里有失败会变色；
  - **工具明细**：每个工具调了几次、失败几次、**被审批拦下几次**（单列，别跟"工具坏了"混着看）、
    平均耗时、最近一次出错原因；
  - **模型通道明细**：请求 / 回复 / 重试 / token / 平均等待（含重试等待）/ 最近出错；
  - **日志**：级别计数 + 最近的告警与错误（可关键字过滤）。
- **说清数据的时效性**（界面里也写了）：运行汇总来自落盘的运行记录（跨重启）；
  **工具与通道的明细是进程内计数，所以是"本次启动以来"**——运行记录只存整次运行的汇总，
  不存"哪个工具调了几次"，所以那一块重启就清零，不拿旧数字冒充现在。
- 「活动追踪」保持原样：它看的是**现在在干什么**（实时阶段与轨迹），可观测性看的是**整体怎么样**（汇总）。

## 安装

1. 下载并运行 `baize-desktop-setup-0.5.7.exe`（用户级安装，不需要管理员）。
2. 已装过旧版：直接运行即可 —— 会自动认出来并按更新走，**安装位置可改**。

## 环境要求与说明

- **需要后端 0.9.23+**（可观测性自 0.9.23 起；板块/阶段/分类 0.9.22 起；内置官方源 0.9.21 起）。
- **WebView2 运行时**：Windows 11 自带；部分 Windows 10 需先安装（装一次即可）。
- 二进制**未做代码签名**，Windows SmartScreen 可能提示 —— 点「更多信息 → 仍要运行」。
