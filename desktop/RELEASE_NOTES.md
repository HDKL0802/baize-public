# 白泽桌面端 0.5.20

控制台**逐页精修**：统一外壳与间距标尺、修掉挤成一坨的表单、补齐空态。

## 本版变化

### 一套共享的书写规范（原来是各页各写各的）
- **页面外壳 `.page`**：20 处内联 `style="padding:14px 16px"` 全部换掉；标题栏不再和卡片内边距互相叠加。
- **动作条 `.bar`**：原来 37 处内联 `display:flex;gap:8/10/16`（三种间距混用）→ 一个类，间距统一走标尺。
- **计数徽标 `.count`**、**危险按钮 `.btn.danger`**、**统计胶囊 `.stat`**：分别替掉了三种计数写法、无差别的删除按钮、以及知识库/记忆里内联仿造的概览胶囊。
- **间距标尺 `--sp-1…--sp-6`（4/8/12/16/20/28）**：内边距与间距一律从这里取，不再就地编数值。
- **节奏**：页面介绍（标题 + 说明）贴近、章节之间拉开 —— 介绍不包卡片，章节才是卡片。

### 逐页修掉的挤 / 缺
- **模型通道**：`Base URL` 原来被 4 列挤到约 300px，长地址断行 → 拆成「名字 / 协议」「Base URL / 模型」两行；API Key 独占整行；「允许远程」「作为回退」从带 `&nbsp;` 占位的格子里挪成独立一行。
- **MCP 服务**：「命令」「URL（http）」「参数（JSON）」原来挤在 3 列里 → 各占整行并改成等宽字体；「手动调一个工具」的调用结果补上「还没调用过」空态。
- **频道**：两个「保存」按钮（同一个动作、用户不知道点哪个）→ 只留一个；表单补上标题；删除/启停/保存收进统一动作条。
- **共享文档**：「刷新」原来单独塞在一张只有按钮的空卡片里 → 并进上方动作条。
- **备份**：8 个勾选项原来硬塞 4 列（长标签换行）→ 改成 `auto-fit` 自适应；备注独占一行。
- **长中文说明溢出**：`公网云端，按量计费`、命中理由这类被塞进 `nowrap` 标签会撑破容器 → 新增可换行标签 `.tag.wrap`；`.mono` 补断词；`.row` 的次要行补省略号。
- **空态**：可观测性的「健康」块在没有通道时只剩标题 → 补「还没有可体检的通道 —— 先去「模型通道」配一条」。
