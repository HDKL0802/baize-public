# 白泽桌面端 0.5.14

两件事：**截图提问**（0.5.13）与**悬浮球迷你对话小窗**（0.5.14）。

## 本版变化

- **悬浮球 · 迷你对话小窗（0.5.14）**
  - **左键单击**悬浮球：主窗口变成 **400×600 的置顶小窗**并跳到「对话」—— 随时问、随时收，不打断手上的事（= 豆包的「小窗」）。
  - 小窗里**只留对话区**：自动藏掉侧栏 / 顶栏 / 状态板块；顶部一条「**⤢ 工作模式**」按钮一键还原。
  - **左键双击** = 直接打开完整窗口；**右键** = 快捷菜单（打开白泽 / 截图提问 / 待审批 / 退出）。
  - 退出「工作模式」会**还原进入前的位置与大小**并取消置顶。
- **截图提问（0.5.13）**
  - 入口：悬浮球右键菜单「截图提问」、侧边栏「系统」组「截图提问」。
  - 抓**整个虚拟屏** → 全屏置顶框选（拖框，`Esc` 取消，过小当全屏）→ 回来做三件事：
    **复制**（`CF_DIB` 进系统剪贴板）/ **提取文字** / **翻译**（中英双语，先译文后原文）。
  - 看图走多模态模型：优先 `kinds` 含 **`vision`** 的通道，否则第一条可用；模型不支持图片时如实报错，不假装识别成功。
  - 落盘 `<数据目录>\shot-latest.png`（另留一份带时间戳的）。
- **实现口径**：抓屏（`GetDC`+`BitBlt`+`GetDIBits`）、框选覆盖层、剪贴板（`GlobalAlloc`+`RtlMoveMemory`+`SetClipboardData`）、
  迷你小窗（`SetWindowPos`）**全部纯 Win32 syscall，零新依赖**；每一步失败只记日志，不影响其它功能。
  界面走本机回环服务（`/api/local/shot/*`、`/api/local/ball/mini`，令牌不进网页），看图走后端 `/api/agent/vision`。

## 安装

1. 下载并运行 `baize-desktop-setup-0.5.14.exe`（用户级安装，不需要管理员）。
2. 已装过旧版：直接运行即可 —— 会自动认出来并按更新走，**安装位置可改**。

## 环境要求与说明

- **需要后端 0.9.28+**（`/api/agent/vision` 看图接口）。
- 悬浮球 / 截图 / 小窗失败**只记日志、不影响启动**（拿不到句柄/建窗失败时其余功能照常）。日志在 `%APPDATA%\白泽\desktop.log`。
- **WebView2 运行时**：Windows 11 自带；部分 Windows 10 需先安装（装一次即可）。
- 二进制**未做代码签名**，Windows SmartScreen 可能提示 —— 点「更多信息 → 仍要运行」。
