# 白泽桌面端 0.5.21

控制台逐页精修**第二批（收尾）**：列表补列头、状态标签归位、空态文案统一。

## 本版变化

- **列表当表格用 → 补列头**（新增 `.row-head`）：任务与审批（待放行 / 最近 40 条）、设备（设备清单 / 待放行）、活动追踪（阶段轨迹）
  原来是一堆 `.row` 直接堆着，现在多了一行淡色的列说明（`动作 · 目标设备 · 来源 | 状态`）。
- **状态标签归位**：任务行的状态原来塞在标题 `<b>` 里（`<b>动作 <span class="tag">状态</span></b>`），
  现在统一挪到右侧 `.tags` —— 和列表里其它状态（在线 / 离线 / 启用）一个位置，扫一列就能看状态。
- **空态文案统一**：`没有命中` → `还没有命中`、`没有在等人工放行的任务` → `还没有待人工放行的任务`、
  `现在没有待处理的冲突` → `还没有待处理的冲突`；单句话结尾的句号去掉。
  另外补了两处缺空态：设置页「桌面控制」的权限档位、模型通道页「手调工具」的调用结果。
- **卡片内次级标题**：账号页「聊天 / 音视频」原来用内联 `style="font-size:13px"` 覆盖 `h3` → 改用共享的 `.h-sub`。
- **页签正文的节奏**：账号页四个页签（身份 / 用户 / 用户组 / 共享文档）的正文介绍原来贴着页签、和其它页不一致，
  现在与页面介绍同一套上下留白。
- **免责声明弹窗**标题的边距改走间距标尺，不再就地写 `8px`。

## 验证

- 19 个页面逐一 `await render()` 真渲染（stub 掉 `fetch`，并给 `/api/state` 打了设备 + 任务 + 轨迹的样例数据）：
  `R n=19 bad=0 rowHead=3 tasksHead=y clean` —— 零渲染错误，新加的列头确实渲染出来了。

## 兼容与说明

- 本轮**只动前端**（`shell.css` + `ui/apps*.js`），后端与手机端无改动。
- 手机端的亮/暗主题仍在下一批。

## 安装

1. 下载并运行 `baize-desktop-setup-0.5.21.exe`（用户级安装，不需要管理员）。
2. 已装过旧版：直接运行即可 —— 会自动认出来并按更新走，**安装位置可改**。
