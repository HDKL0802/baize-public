# 白泽桌面端 0.4.1

新增「人设」应用 + 修复左侧导航图标。

## 本版变化

- **新增「人设」应用**（对应后端 0.9.2）：
  - 编辑决定白泽「是谁、按什么规矩办事」的 Markdown 人设文件（AGENTS / SOUL / PROFILE，可自建）；
  - 支持 启用·停用 / 上下排序（决定拼进系统提示的顺序）/ 恢复默认模板 / 归档删除 / 人设总开关；
  - **拼装预览**：实时显示白泽实际读到的提示开头与 token 估算；
  - 改完保存**立即生效**（后端每次运行现读，不用重启）。
- **修复左侧导航图标**：上一版把 SVG 图标直接塞进容器、没带 `<svg>` 包裹，图标全部渲染成 0×0 不可见；现已统一用 `iconSvg()` 输出，13 个应用的线性图标全部正常显示。
- 内置应用从 12 个增到 **13 个**（新增：人设）。

## 安装

1. 下载并运行 `baize-desktop-setup-0.4.1.exe`（用户级安装，不需要管理员）。
2. 也可用 0.4.0 的「检查更新」直接升上来（更新包由后端 `GET /dl/` 分发）。

## 环境要求与说明

- **需要后端 0.9.2 及以上**（人设接口是这次新增的）。
- **WebView2 运行时**：Windows 11 自带；部分 Windows 10 需先安装（装一次即可）。
- 二进制**未做代码签名**，Windows SmartScreen 可能提示 —— 点「更多信息 → 仍要运行」。
