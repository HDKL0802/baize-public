# 白泽桌面端 0.5.4

插件市场：装插件 = 往技能库和 MCP 配置里加东西，一部界面搞定。

## 本版变化

- **「插件市场」（新应用，能力分组）**：三个页签 —— 市场 / 已安装 / 插件源。
  - **插件就是静态文件**：一个源的 `index.json` + 若干 `.zip`。所以插件源**不需要任何服务端**，
    扔在任意静态托管上都行；也支持**本地目录 / 本地 zip 包**（离线安装、或装你自己打的包）。
  - **市场页签**：列出各源的货架（说明 / 版本 / 作者 / 许可证 / 标签），已装的标「已装」、
    版本落后的标「有更新」；一键安装/卸载。也可以直接填一个 `.zip` 的网址或本机路径安装。
  - **已安装页签**：这个插件带了哪些**技能**、登记了哪些 **MCP 服务**、从哪来、什么时候装的，
    以及安装时的说明（比如"源没提供 sha256，本次未做完整性校验"、"技能 X 与现有的重名，已跳过"）。
    可**停用 / 启用 / 卸载**。
  - **插件源页签**：增删源、启停源；**每个源的拉取状态单独显示**，某个源挂了只影响它自己，
    不会把整个市场变成空白（也不会假装那个源是空的）。
- **安全与克制（这套东西会写你的技能库和配置，所以口径要较真）**：
  - 解包挡 **zip slip**（`..`、绝对路径）、挡**符号链接**、限文件数与总解包体积（防 zip 炸弹）。
  - 源里给了 `sha256` 就**逐字节校验**；没给就**明确写在安装说明里说没校验**，不假装验过。
  - 包内声明的 id 与源里登记的不一致 → **直接拒装**（防"货不对板"）。
  - 与你现在已有的**同名技能 / 同名 MCP 服务一律跳过**，绝不覆盖你自己的东西（插件的优先级永远低于你）。
  - **卸载是归档**：技能与原始包一起挪到数据目录的 `plugins/_removed/`（能捞回来）；
    **停用是移位**：技能的"活"副本挪进插件自己的 `store/<id>/.off`（保留你的改动），启用时再挪回去。

## 安装

1. 下载并运行 `baize-desktop-setup-0.5.4.exe`（用户级安装，不需要管理员）。
2. 已装过旧版：直接运行即可 —— 会自动认出来并按更新走，**安装位置可改**。

## 环境要求与说明

- **需要后端 0.9.19+**（插件市场自 0.9.20 起；账号 0.9.18 起、冲突协商 0.9.19 起）。
- 默认**不预置任何插件源**（不编造一个并不存在的官方地址）：空市场会直接告诉你「去加一个源，或直接给个 zip」。
- 插件带 MCP 服务时，远端地址仍受后端 `allowRemote` 开关约束 —— 没放开会**如实告诉你没登记上**，不会静默跳过。
- **WebView2 运行时**：Windows 11 自带；部分 Windows 10 需先安装（装一次即可）。
- 二进制**未做代码签名**，Windows SmartScreen 可能提示 —— 点「更多信息 → 仍要运行」。
