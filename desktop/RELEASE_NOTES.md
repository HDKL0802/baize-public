# 白泽桌面端 0.5.18

控制台审美收敛第一批 + 对话页重做（工作 / 聊天双模式）。

## 本版变化

- **控制台审美收敛（所有页面统一受益）**
  - **卡片化分组**：`.sect` 从"靠分割线"改成**有底有边的分组卡**（统一 14/16px 内边距），
    用留白与分组替掉一长串横线 —— 设置、模型通道、技能、插件、可观测性等页的层次一下子清楚了。
  - **统一基准**：8px 间距栅格、三档字色（正文 / 次要 / 更弱）、`.sub` 行高 1.7、
    表单控件内边距 7/9px、`.fields` 间距 12px、`.pre` 与 `.empty` 行高统一。
- **对话页重做：工作 / 聊天 双模式 + 「最近运行」侧栏**
  - 顶部两个页签：**聊天**（一句一句说，来回摊在消息流里）/ **工作**（把「目标」写清楚再派活）。
  - 右侧常驻 **「最近运行」** 侧栏：最近跑了什么、什么状态、多少步 / 多少 token、什么时候跑的；
    点一条就切到「工作」模式看当前状态。
  - 聊天流里的消息用气泡区分「我 / 白泽」，魔法命令的回执、失败原因都直接落在消息里。
  - `Ctrl+Enter` 发送。

## 兼容与说明

- **需要后端 0.9.28+**（`/api/agent/vision` 看图接口）。
- 本轮**只动前端**（`shell.css` / `ui/apps.js`），后端与手机端无改动。
- 抓屏 / 框选 / 剪贴板 / 浮窗失败**只记日志、不影响主程序启动**。日志在 `%APPDATA%\白泽\desktop.log`。
- **WebView2 运行时**：Windows 11 自带；部分 Windows 10 需先安装（装一次即可）。

## 安装

1. 下载并运行 `baize-desktop-setup-0.5.18.exe`（用户级安装，不需要管理员）。
2. 已装过旧版：直接运行即可 —— 会自动认出来并按更新走，**安装位置可改**。
