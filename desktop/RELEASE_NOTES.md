# 白泽桌面端 0.3.1

**首个带安装包的版本。** Windows 10/11 x64，纯 Go + WebView2（无 Node、无 Rust、无 C 编译器），单文件 exe。

## 本版亮点

- **安装包**：`baize-desktop-setup-0.3.1.exe` —— 用户级安装（`%LOCALAPPDATA%\Programs\Baize`，**不需要管理员**），自带开始菜单/桌面快捷方式与卸载器，安装时可勾选「开机自动启动」。
- **常驻托盘**：点窗口的 ✕ 不再退出，只隐藏到托盘 —— 设备连接**不掉线**。托盘左键开合窗口，右键菜单「打开 / 退出」。
- **单实例**：重复启动不会开出第二个窗口，而是把已经存在（可能隐藏着）的窗口唤到前台。
- **开机自启**：设置里可随时开关（写用户级 `HKCU\...\Run`，与安装包勾选同口径）。
- **自动更新**：从后端 `GET /dl/` 拉更新包 → 比对版本 → 校验 sha256 → 自动替换并重启。
- **12 个内置应用**：对话 / 设备 / 任务与审批 / 知识库 / 记忆 / 模型通道 / MCP / 技能 / 定时任务 / 备份与恢复 / 活动追踪 / 设置。

## 安装

1. 下载并运行 `baize-desktop-setup-0.3.1.exe`。
2. 首次启动填写后端地址与配对令牌；也可命令行传 `--server http://<host>:8787 --token <令牌>`。

## 环境要求与说明

- **WebView2 运行时**：Windows 11 自带；部分 Windows 10 需先安装（装一次即可，之后自动复用）。
- 二进制**未做代码签名**，Windows SmartScreen 可能提示 —— 点「更多信息 → 仍要运行」。
- 支持 Windows 10 1809 (x64) 及以上。
- 安装包与自动更新包同源：发布脚本会把裸 exe 传到后端 `/dl/`，安装包则作为 Release 附件提供。
