# 白泽桌面端 0.5.27

「电脑控制」第 2 档：**允许执行命令** —— 让白泽在这台电脑上跑你圈定的命令（默认关闭，三重闸门）。

## 本版变化

- **设置 → 桌面控制 新增一节「允许执行命令（第 2 档 · 高危）」**：
  - 一个**显式开关**（默认关；打开要过风险确认 + 二次确认弹窗）；
  - 一份**命令白名单**（每行一条，只写命令名，如 `dir` / `ipconfig` / `git`）。
- **三重闸门，缺一不可**（都在**本机**判定，后端绕不过）：
  1. **本机开关**：不开就是一条也跑不了（`sys.exec` 这条能力**根本不上报**给后端，它也就派不过来）；
  2. **命令白名单**：命令名（取 basename、去掉 `.exe/.cmd/.bat`，小写）必须在清单里 ——
     ⚠️ **空清单 = 一条都不许跑**（与"空=不限制"的惯例相反：这是高危能力，宁可默认谁都跑不了）；
     并且**拒绝管道 / 重定向 / 串联 / 命令替换**（`;` `|` `&` 反引号 `$` `>` `<` 换行）——
     否则 `dir; rd /s /q D:\` 的第一个词是 `dir`、照样能过白名单，那白名单只是心理安慰；
  3. **后端人工审批**：`sys.exec` 是危险动作，**每次**派下来都要在弹窗里点「批准并执行」（复用现成闸门）。
- **执行侧护栏**：单次超时（默认 60 秒 / 上限 300 秒）、输出上限 256KB（超出截断并标注）、
  超时自动终止并把原因写进回执。
- **协议/后端**：新增设备动作 `sys.exec`（进白名单；它本就在「危险动作前缀」里，所以**强制审批**是自动生效的）；
  无界面端（`agent/internal/executor`）实现同款执行，但**默认一律拒绝**，只有显式 `--allow-danger` 或 `--dry-run` 才放行。

## 兼容与说明

- 后端同期升到 **0.9.35**。手机端 **0.10.16 未改动**。
- 这一档**与文件权限档位不是一条轴**：想跑条命令不必先把整个盘放开；反过来，开了命令执行也不会自动给文件读权限。
- 说明白：允许执行命令 = 把这台电脑的命令行交给智能体（白名单内）。**请只放你信得过的命令**，并保持人工审批开启。

## 安装

1. 下载并运行 `baize-desktop-setup-0.5.27.exe`（用户级安装，不需要管理员）。
2. 已装过旧版：直接运行即可 —— 会自动认出来并按更新走，**安装位置可改**。
