# 白泽桌面端 0.4.0

**界面重做**：从「桌面型外壳」改回**标准智能体界面** —— 左侧导航 + 单内容区，和一个正常的桌面应用一样。

## 本版变化

- **界面改为标准布局**：左侧分组导航（核心 / 知识 / 能力 / 系统）+ 一个内容区 + 顶栏。去掉了之前的桌面、浮动窗口、底部 Dock、启动台那一套。
- **标题栏不再发白**：Windows 原生标题栏改为深色、并对齐界面配色（`DwmSetWindowAttribute`）。
- **导航图标重做**：原来的 emoji（💬🖥️📋…）换成一套统一的**单色线性 SVG 图标**，跟着主题色走。
- **应用图标重做**：深色圆角底 + 白色神兽「白泽」头像；任务栏、托盘、安装包、卸载器统一同一枚（源图 `assets/icon-src.png`，由 `build-icon.ps1` 裁切 + 圆角遮罩 + 生成 7 档 `.ico`）。
- **不再弹 CMD 黑窗**：程序按 GUI 子系统链接，启动不再弹出控制台窗口；运行日志改写到 `%APPDATA%\白泽\desktop.log`。
- **安装包**：`baize-desktop-setup-0.4.0.exe` —— 用户级安装（`%LOCALAPPDATA%\Programs\Baize`，不需要管理员），自带开始菜单/桌面快捷方式与卸载器。

## 保留的能力

- **常驻托盘**：点窗口的 ✕ 只隐藏到托盘，设备连接不掉线；托盘左键开合、右键菜单。
- **单实例**：重复启动只把已有窗口唤到前台。
- **开机自启**：设置里可随时开关（用户级 `HKCU\...\Run`）。
- **自动更新**：从后端 `GET /dl/` 拉更新包，校验 sha256 后自动替换并重启。
- **12 个内置应用**：对话 / 设备 / 任务与审批 / 知识库 / 记忆 / 模型通道 / MCP / 技能 / 定时任务 / 备份与恢复 / 活动追踪 / 设置。

## 安装

1. 下载并运行 `baize-desktop-setup-0.4.0.exe`。
2. 首次启动填写后端地址与配对令牌；也可命令行传 `--server http://<host>:8787 --token <令牌>`。

## 环境要求与说明

- **WebView2 运行时**：Windows 11 自带；部分 Windows 10 需先安装（装一次即可）。
- 二进制**未做代码签名**，Windows SmartScreen 可能提示 —— 点「更多信息 → 仍要运行」。
- 支持 Windows 10 1809 (x64) 及以上。
