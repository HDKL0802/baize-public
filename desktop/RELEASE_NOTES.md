# 白泽桌面端 0.5.23

悬浮球长出了「耳朵」：**语音转写**（麦克风录音 → 文字 → 存成笔记）与**实时双语字幕**（贴屏幕底部的置顶横条，说一句显示一句）。

## 本版变化

- **语音转写浮窗**（悬浮球右键 → 语音转写，或 `Alt+Shift+D`）：按住麦克风录音，**每 5 秒自动切一段**送去听写，
  边录边出字，每行带时间戳；底部可以「保存为笔记」（落到后端笔记库，标题 `语音转写 <日期 时间>`）、
  「复制全部」、「清空」。
  ⚠️ **不做说话人分离**：当前语音通道（dashscope paraformer-realtime / OpenAI 兼容 whisper）都不提供
  说话人分离，所以转写结果里不会有「说话人 A/B」——浮窗里也如实写明了这一点。
- **实时双语字幕**（悬浮球右键 → 实时字幕，或 `Alt+Shift+C` 开 / 关）：一条**贴屏幕底部的置顶横条**，
  宽约铺满工作区；每 3.8 秒一段听写，随后翻译，上行原文、下行译文，只保留最近 3 条（越新的越亮）。
  迷你操作条上可切**译文语言**（中 / English）、**显示原文开关**、**字号三档**（小 / 中 / 大）。
  - 字幕条 `WS_EX_NOACTIVATE` + `SWP_NOACTIVATE`：**不抢焦点**，你原来的窗口（电影 / 播放器）不会被顶下去。
  - 翻译走新后端接口 `POST /api/agent/voice/translate`（用你配的第一条可用模型通道）。
    **翻译失败不会丢掉原文**：译文位置直接写「翻译失败：<原因>」。
  - ⚠️ **拾音方式是麦克风**（对着扬声器外放也能用）。真正的「系统内录（WASAPI loopback）」需要额外的原生音频采集，
    本轮没做 —— 这一点如实说明，不假装支持。
- **全局快捷键**：`Alt+Shift+S` 截图提问（原有）、`Alt+Shift+D` 语音转写、`Alt+Shift+C` 实时字幕（开 / 关）、
  `Alt+Shift+Q` 对话浮窗。被别的程序占用时**如实标出「没抢到」**（设置页 →「快捷键」那一节），不会假装配好了。
- **设置页新增两节**：「语音转写与实时字幕」（字幕语言 / 字号 / 显示原文 + 一键打开两个浮窗）、
  「快捷键」（系统级快捷键清单 + 真实注册状态）。
- **顺手修掉一个老 bug**：浮窗页 `float.html` 里的 `hidden` 属性**一直是失效的**（作者样式 `display:flex` 盖掉了
  UA 的 `[hidden]{display:none}`），也就是对话 / 提取文字两个区块以前是**同时显示**的。补了一条
  `[hidden]{display:none!important}` 兜底。

## 验证

- `go build ./...` / `go vet` / **`go test ./... -count=1` 全绿**；后端新增用例见下（翻译接口 4 个 + 端点 2 个）。
- **四种浮窗模式**（chat / extract / dictate / subtitle）逐个无头 Edge 真渲染，实测计算样式：
  恰好各显示一块，字幕模式下顶部拖动条也确实收起（`head=none`）。
- **设置页真渲染**（无头 Edge + 打桩 fetch，走 http 以拿到真实报错位置）：
  `OK`，字幕语言 / 字号 / 显示原文的选中态与后端配置一致，快捷键那节正确渲染出「没抢到」及原因。
- **真进程冒烟**：起 `desktop.exe -float=subtitle` 子进程，实测 `/api/local/float/mode` 返回
  `{"mode":"subtitle","title":"白泽 · 实时字幕"}`、`/api/local/subtitle` GET/POST 落盘生效、
  `/api/local/hotkeys` 四项注册成功、`/api/local/float/open` 对 `../../evil` 这类模式名**白名单拒绝**
  （模式名会被拼进 profile 路径，放行任意字符串就是路径穿越）。
- **真接口实测**（本地起真后端 + 真 DeepSeek 通道）：`en→zh` 得「你好，世界。很高兴认识你。」、
  `zh→en` 得 "The weather is nice today. Let's go out for a walk."；空文本 / 超长 2001 字各回 400；
  非法 `to=fr` 按中文处理；未开语音通道时 `/voice/stt` 如实回「语音通道还没打开」；无令牌 401。

## 兼容与说明

- 后端同期升到 **0.9.32**（新增 `POST /api/agent/voice/translate`）。手机端 **0.10.16 未改动**（这两个浮窗是桌面端专属）。
- 语音转写与字幕都依赖「语音通道」已配置（听写模型）与至少一条可用模型通道（翻译）。

## 安装

1. 下载并运行 `baize-desktop-setup-0.5.23.exe`（用户级安装，不需要管理员）。
2. 已装过旧版：直接运行即可 —— 会自动认出来并按更新走，**安装位置可改**。
