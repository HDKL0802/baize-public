# 白泽桌面端 0.5.25

这一版专治「界面看着别扭」+ 把几个**已经能做、只是没绑键**的快捷键补上。

## 本版变化

- **原生标题栏跟着主题变色**（用户点名的黑条/白条问题）：
  - 以前标题栏**写死深色** —— 切到亮色界面后，顶上那一行（应用名 / 图标 / 最小化·关闭）
    还是深条，跟下面完全对不上。
  - 现在 `applyTitleBarTheme` 按**当前主题**刷标题/文字/边框三色：暗色配深条、亮色配白条/浅条；
    「跟随系统」时跟 Windows 个性化里的「应用使用浅色主题」。
  - 改主题**立即生效**（不再需要重启）；「跟随系统」时另外每 20 秒对一次（用户切了系统深浅色也能跟上）。
- **浮窗主题即时生效**：以前浮窗（对话/转写/字幕等独立进程）改了主题要**关掉重开**才变；
  现在每 4 秒对一次本地配置，主题一变立刻刷（不用关窗）。
- **对话浮窗拆成「对话 / 进展」两个页签**（原来运行状态挤在聊天流里，又乱又丑）：
  「对话」只管聊天；「进展」单独一页显示白泽正在干什么（每 3 秒刷，带状态/步数/token 列表）。
- **发送按钮挪到输入框上方**（照豆包那套：先按钮、后输入），输入框回车即发。
- **回车发送**：对话浮窗、主界面「对话」「工作」两处 —— `Enter` 发送、`Shift+Enter` 换行
  （以前只认 `Ctrl+Enter`，现在也保留）。
- **主界面对话页加了 ↑↓ 翻历史**：最近 30 条派过的目标，单行输入时 `↑` 往回翻、`↓` 往前翻。

## 验证

- 桌面端 `go build` / `go vet` 全绿；`gofmt` 干净。
- UI：主界面 8 个脚本 + `float.html` 内联脚本无头解析全 OK（`R n=9 clean`）。
- 真进程冒烟：起 `desktop.exe -float=chat`，`/api/local/float/mode` 正常；主题接口 POST 后标题栏刷新路径被调用（日志可见）。

## 兼容与说明

- 后端仍 **0.9.33**（本版零后端改动）；手机端 **0.10.16 未改动**。
- 「跟随系统」的主题在 Windows 上要读到注册表 `AppsUseLightTheme`；读不到时按深色处理（与界面一致）。

## 安装

1. 下载并运行 `baize-desktop-setup-0.5.25.exe`（用户级安装，不需要管理员）。
2. 已装过旧版：直接运行即可 —— 会自动认出来并按更新走，**安装位置可改**。
