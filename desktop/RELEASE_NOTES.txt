桌面端 0.5.23：悬浮球新增「语音转写」与「实时双语字幕」两个浮窗 + 四个全局快捷键。

新增
- 语音转写浮窗（Alt+Shift+D）：麦克风录音 → 每 5 秒一段听写 → 边录边出字，可保存为笔记 / 复制 / 清空。
  不做说话人分离（当前语音通道不提供），界面已如实写明。
- 实时双语字幕（Alt+Shift+C 开/关）：贴屏幕底部的置顶横条，原文 + 译文两行，可切译文语言 / 显示原文 / 字号三档；
  不抢焦点（WS_EX_NOACTIVATE），你原来的窗口不会被顶下去。翻译走新接口 /api/agent/voice/translate。
  拾音是麦克风（外放也能用）；系统内录本轮未做，如实说明。
- 全局快捷键：Alt+Shift+S 截图提问 / +D 语音转写 / +C 实时字幕 / +Q 对话浮窗；被占用会如实标「没抢到」。
- 设置页新增「语音转写与实时字幕」「快捷键」两节。

修复
- float.html 的 hidden 一直失效（作者 display:flex 盖掉 UA 规则），导致对话与提取文字两个区块同时显示；已补兜底。

后端同期 0.9.32（新增 /api/agent/voice/translate）；手机端 0.10.16 未改动。
