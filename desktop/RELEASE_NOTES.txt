桌面端 0.5.4：插件市场（装插件 = 加技能 + 加 MCP 服务）
- 新增「插件市场」：市场（货架 / 一键装 / 也可直接给 zip 网址或本机路径）/ 已安装 / 插件源 三个页签
- 插件是纯静态文件（源的 index.json + 若干 zip）：不需要任何服务端，也支持本地目录与本地 zip
- 校验与克制：sha256 有就验、没有就明说没验；解包挡 zip slip/符号链接/体积炸弹；同名技能与 MCP 一律跳过不覆盖
- 卸载=归档到 plugins/_removed（能捞回）；停用=技能挪进 .off（保留改动），启用再挪回
- 每个插件源的拉取状态单独显示，某个源挂了不影响别的源
- 需要后端 0.9.20+（插件市场 0.9.20 起）
