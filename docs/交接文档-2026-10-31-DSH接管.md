## 4. 踩坑记录

1. **PowerShell 5.1 不支持 `if` 作表达式**（`(if(...){}else{})` 会报错），必须用 `$st="A"; if(...){$st="B"}` 写法。
2. **后台任务在会话重启后会丢失**（`unknown job`），长任务要确认 job 还在。
3. **`go build` 在仓库根目录必失败**：根目录无 `go.mod`，报 `cannot find main module`。必须 `go -C agent build`。
4. **验证后端务必用隔离数据目录 + 非 8787 端口**，否则会污染活库或端口冲突。
