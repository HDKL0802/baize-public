## 二、SteamCommunity 302 v2 调研结论：不内置

详见 [接入调研-SteamCommunity302-V2.md](./接入调研-SteamCommunity302-V2.md)。

要点：
- 官方项目为 `dogfight360.com/blog/18682/`（作者 羽翼城/Dogfight360），当前 Ver.15.0.9；**未找到可核实的官方源码仓库，许可证未核实**，不能随白泽再分发。
- Linux 版为带界面的 AppImage，安装/启动服务需要 **root**；默认监听 **80/443**；需要导入系统级 CA；hosts 模式写系统 hosts；DNS 重定向模式装驱动，已知与 Vanguard 冲突。
- 与白泽"用户级安装 + 非特权容器 + 仅 8787"的形态冲突，**判定不能整建制内置**。没有实施任何 302 相关代码。

## 三、更新功能与后端解耦

改动点：`desktop/webui/src/views/SettingsView.vue`
- 新增「桌面端更新」卡片，调用本机 Go 壳：
  - `GET /api/local/update/check`（`desktop/update_windows.go:452`）
  - `POST /api/local/update/apply`（`update_windows.go:461`）
- 这两个接口不经后端代理，后端未连接时仍可用。流程：GitHub → Gitee → 后端三级回退取 manifest；下载 zip；sha256 校验；替换 `ui/` 与 exe；起新进程并退出（`update_windows.go:208`）。
- 降级路径：失败时保留当前版本并在页面显示具体错误；用户也可从 Releases 手动下载覆盖安装（界面已写明）。
- 页面打开时静默检查一次桌面端版本，不打扰。
