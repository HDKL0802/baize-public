## 2. B 文件浏览器

- 视图：`desktop/webui/src/views/FilesView.vue`，路由 `files`，导航名「电脑文件」。
- 能力：盘符起点、面包屑、目录优先、上一层、权限横幅、文本/图片/PDF 预览、目录内按文件名递归搜索。
- 安全：所有请求都过 `permGate`（`desktop/perm.go`），范围由「设置 → 桌面控制」决定；**没有**任意路径读写，也**没有** delete/open-with-system。
- 新增接口：`GET /api/local/files/search?path=&q=`（`desktop/files_windows.go`）。
  - 边界：最多 300 条结果、最多访问 20000 条目、最多 8 层；`WalkDir` 不跟随符号链接/目录联接。
  - 只匹配文件名，不读文件内容；`root` 为空不允许搜索（「此电脑」不递归）。
- 预览限制：文本 >4MB、图片/PDF >12MB 不加载（界面说明原因）；不是通用文档渲染器。

## 3. C 独立知识库（笔记型 + 知识星图）

### 3.1 REA-Obsidian 调研结论

`d:\xm\REA-Obsidian` 的实际内容：

- `obsidian-unpacked-1.45.5/`、`obsidian-unpacked/`：Obsidian 原厂安装包解包产物（`app.js` 3.9MB webpack、`main.js`、`worker.js` 等）。
- `probe_*.mjs` / `probe_*.json` / `rea-evidence.json`（73MB）/ `rea-evidence-1.14.5.json`（266MB）：逆向证据与函数探针。
- 结论：**没有可复用的自有笔记/星图实现**；原厂 bundle 闭源，不能嵌进白泽。故本轮**零改动**该项目（只读），避免把它改坏。

### 3.3 新增界面

- `desktop/webui/src/views/KnowledgeView.vue`，路由 `kb`，导航名「独立知识库」。
- 功能：目录分组/折叠、笔记树、预览/源码切换、编辑/新建/删除、改路径即重命名、
  全文搜索、标签筛选、出链/反链、重建索引、自动连边（共引）、重解悬空、星图页。
- 预览是轻量 Markdown：标题/列表/代码/粗体/双链/标签可点；不解析表格、图表、附件嵌入。
- 「从本机导入」适配层：桌面端 `/api/local/files/search` 找 `.md` → `/api/local/files/read` 读文本

  - 上限：最多 300 个文件、8 层；单文件读取接口 16MB；单篇 >4MB 跳过并计数。

- 笔记库按登录身份分区，`vault/` 目录本身可被 Obsidian 直接打开；但**不支持运行期挂载任意外部目录**。
- 星图 `root/hops` 聚焦后端已支持，界面暂未加入口。
- 附件嵌入（`![[x.png]]`）目前只参与建边，预览不渲染。

## 4. D 内置浏览器

### 4.1 选型与版本策略

- 内核：**Microsoft Edge WebView2 Evergreen**（Chromium，跟系统上的 Edge 同源），不打包、不冻结内核。
- “最新”怎么保证：由 Microsoft Edge Update 维护；白泽每次打开/刷新都从注册表读**实际版本**并显示。
  本机实测：WebView2 `155.0.4283.62`，Edge 稳定版 `154.0.4258.53`（同代，未落后）。
- 界面会对比 Edge 稳定版第一段版本号；明显落后时提示“更新通道被策略/代理/离线挡住”，不谎称最新。

### 4.2 离线退化（如实标注）

- 目标机**没装 WebView2 Runtime 且无网络**：内置浏览器启动失败并报错，白泽**不会**静默下载安装。
- 离线装机：需随安装包预置 WebView2 Evergreen 独立安装器，或部署固定版本运行时目录
  （`WEBVIEW2_BROWSER_EXECUTABLE_FOLDER`）；固定版本**不会自动更新**，需人工升级。
- **未验证**：断网环境下运行时能否自行更新（不做承诺）；本轮只在联网本机验证了启动与页面桥。

### 4.3 新增内容

- `desktop/browser_engine_windows.go`：只读注册表探测 WebView2 版本/位置/渠道，并对比 Edge 稳定版；
  识别 `WEBVIEW2_BROWSER_EXECUTABLE_FOLDER` 固定版本部署。结果并入 `/api/local/browser` 的 `engine` 字段。
- `desktop/webui/src/views/BrowserView.vue`，路由 `browser`：
  - 内核卡片（版本、渠道、位置、与 Edge 对比、版本策略与离线说明）；
  - 控制开关（允许控制浏览器 / 允许 Chrome 扩展，两者分开授权，开启需二次确认）；
  - 打开/移交/收回/关闭；当前 URL/标题/readyState/handoff 状态；8 秒轮询；
  - Chrome 扩展端口、令牌（复制/重置）、连接状态、打开扩展目录。
- 控制口仍只监听 `127.0.0.1`，每个请求带随机令牌；浏览器在独立 `-browser` 子进程里运行。

### 4.4 实测记录

用临时编译的桌面端二进制启动 `-browser` 子进程（端口 38101、测试令牌）：

- `/health` 在 30 秒内返回 `ready=true`（WebView2 初始化完成）；
- `POST /ctl {"action":"status"}` 返回页面状态，`readyState` 为 `complete`；
- 验证后已结束临时进程。
