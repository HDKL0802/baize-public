## 四、踩坑 / 注意事项

1. **PowerShell `$args` 是自动变量**：写 `function Try-Push($label, $args)` 再用 `& git @args` splatting 会失效，git 收到空参数只打印 usage（exit 1）。改名 `$GitArgs` 后正常。
2. **插值字符串里别嵌套分号语句**：`"$s ignored=" + (git ...; $LASTEXITCODE -eq 0)` 触发 `MissingEndParenthesisInExpression`。改分步赋值 `$ok = ($LASTEXITCODE -eq 0); "$s ignored=$ok"`。
3. **所有 git 操作必须带 `git -C D:\xm\白泽智能体`**：在 pwsh 默认 cwd=`G:\DeepSeek Harness` 直接跑会报 `fatal: 'origin' does not appear to be a git repository`。
4. **中文路径 + makensis**：`build-installer.ps1` 会把 nsi/exe/ui/float/browser-ext/icon.ico 复制到 `%TEMP%\baize-installer`（ASCII 路径）再编译，避开中文路径失败；`installer.nsi` 必须是 UTF-8 BOM（前 3 字节 `239,187,191`）。
5. **Go 分模块构建**：必须 `go -C agent|core|desktop build`，且 `CGO_ENABLED=0`；后端 `version` 由 `-ldflags -X main.version=` 注入（CI 与本地补齐脚本一致）。
6. **凭据不落盘**：Gitee / GitHub 令牌只在内存（`git credential fill` 或环境变量），`deploy.local.env`、`凭据清单-明文.md`、`agent/data/*` 全被 `.gitignore` 忽略，禁止提交进 Git、禁止推公开仓。
7. **公开仓 Release 匿名可达、私有仓不可达**：故 Release 只发 `baize-public`；GHCR 包只在私有仓 `baize` 推（`docker.yml` 的 `push` 条件）。
