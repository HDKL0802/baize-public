## 六、踩坑 / 教训

1. `go-webview2 -debug` ≠ CDP 端口（只开 DevTools/右键菜单）；别指望靠它拿 9222 做自动化。
2. `browser_eval` 的 expression 必须是**单个 IIFE**（`(() => { ... })()`），写多条顶层语句带分号会报 `page.evaluate: SyntaxError: Unexpected token ";"`。
3. 视图文件在 `webui/src/views/`、组件在 `webui/src/components/`、`store/conn.js` 在 `webui/src/store/`（不在 `src/` 根）。
4. PowerShell `Get-Content` 读中文 mojibake 是 GBK 显示假象（`index.html` title「鐧芥辰」= 白泽，非损坏）；`tools.read` 校验为准。
5. `cap.ps1` 直接 `&` 被执行策略拦（禁止运行脚本）→ 改 pwsh 内联 `Add-Type` + `System.Drawing.CopyFromScreen`。
6. `window.confirm` 原生弹窗会卡住 DOM 自动化 → 页面内 override 为 `()=>true` 放行（仅测试页内，不改产品代码）。
7. `git credential fill` 对 github.com 有存储凭据（`username=HDKL0802`），对 gitee.com 无 → 推前分别核验，别一律当可用。
