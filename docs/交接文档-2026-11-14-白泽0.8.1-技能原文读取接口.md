## 一、本次改了什么

### 1. 为什么要做这个（问题是真的，不是想象）

桌面端「技能」页原来编辑一个技能时，是拿后端解析后的三个字段（`name` / `description` / `body`）
**在浏览器里重组**出一整篇 SKILL.md 再保存。后果：原文件 front-matter 里除 `name`、
`description` 之外的**任何其它字段都会在这一存之间消失** —— `triggers`、`version`、
自定义键全丢。旧界面上其实写了这句话，但这正是用户最讨厌的那种「看起来能用其实不能用」：
保存成功、功能正常、但数据被悄悄改没了。

### 2. 改动（3 个文件，129 插入 / 13 删除）

| 文件 | 改动 |
|---|---|
| `agent/internal/httpapi/agent_cron_skills_api.go` | 新增 `GET /api/agent/skills/raw?name=<技能名>`：按目录名或展示名定位技能，**直接读磁盘上的 SKILL.md 正本**返回（`{name, slug, content, bytes}`），一个字节不重组 |
| `agent/internal/httpapi/agent_cron_skills_test.go` | 新增 `TestSkillRawRead`：造一份带 `triggers` / `version` 的 SKILL.md，断言原文接口能原样读出这些字段 |
| `desktop/webui/src/views/SkillsView.vue` | `openEdit` 改 async：先拉原文再进编辑器；**读取失败直接报错并停止编辑**，不再用重组内容伪装成功 |

### 3. 接口口径（明确报错，不静默）

| 情况 | HTTP | 说明 |
|---|---|---|
| 缺 `name` 参数 | **400** | 「需要技能名（name）」 |
| 技能不存在 | **404** | 「找不到技能：xxx」 |
| 读盘失败 | **500** | 「读取 SKILL.md 失败：<底层原因>」 |
| 正常 | **200** | `{name, slug, content, bytes}` |

- `name` 既接受**目录名**（如 `triage`）也接受**展示名**（如「分诊」）—— 复用既有
  `resolveSkillName` 归一逻辑，界面上看到哪个名字都能定位到同一个技能。
- 复用既有 `skillSlug(sk)`（`filepath.Base(filepath.Dir(sk.Path))`）与 `a.Skills()`，
  **不新增第二套技能定位逻辑**。

## 四、踩坑

1. **makensis 读中文路径会乱码**（`D:/xm/����������/desktop/installer.nsi`）→ 改在
   纯 ASCII 目录 `C:/bz081work` 复制 `installer.nsi` + `assets/icon.ico` + `bin/` 产物后编译。
2. `installer.nsi` 的 `ICON` 默认值是 `${__FILEDIR__}\icon.ico`，但真实图标在
   `desktop/assets/icon.ico` → 必须显式 `-DICON=<abs path>`，否则报
   `Error while loading icon ... can't open file`（第 59 行 abort）。
3. `installer.nsi` 用 `File "${ROOTEXE}"` / `${UIDIR}` / `${FLOATDIR}` / `${EXTDIR}` 取文件，
   编译目录里必须按 `baize-desktop.exe` + `ui/` + `float/` + `browser-ext/` 平铺摆放。
4. 本机 **PowerShell 不在 PATH**（`spawnSync powershell.exe ENOENT`）→ `desktop/build.ps1`
   / `build-installer.ps1` 跑不了，改用 `cmd.exe` 手工走等价步骤（npm run build →
   go build → 拷贝 UI → makensis）。
5. `go build -o bin/baize-backend-linux-amd64` 必须从 `agent/` 目录并把输出指向
   `../desktop/bin/...`；先前误输出到 `agent/bin/` 的那份是旧版本，**以 `desktop/bin/`
   这份为准**。
6. 交叉编译的 Linux 二进制**不能在 Windows 直接跑** → 版本自检走 WSL
   （`wsl.exe -e bash -lc .../baize-backend-linux-amd64 --version`）。
7. `git commit` 需显式 `-c user.name=HDKL0802 -c user.email=...` 并让子进程带上
   `HOME`/`USERPROFILE`，否则报 `Author identity unknown ... Administrator@DESKTOP-3IM4KHB.(none)`。
