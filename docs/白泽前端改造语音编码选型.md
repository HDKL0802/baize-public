## 一、前端：Vue 3 + Naive UI（已定，最终确认）
| 项 | 定论 |
|---|---|
| 框架 | **Vue 3**（不用 Vue2） |
| UI 库 | **Naive UI**（V.N.A.I.V.E，轻、好看、中文文档全） |
| 构建 | **Vite**，输出**动态 SPA**（解决你"静态做不成"的问题——现在是手写静态 HTML，改成 Vue3 动态渲染应用） |
| 后端 | Go 只 serve 构建产物，**不推翻** |
| 手机端 | **也用 Vue3**，与桌面同步（一套组件编译成手机 H5） |
| 运行时重量 | Vue3 gzip ~30-50KB + Naive UI 按需引入，符合省内存 |

### 改造顺序（按你定的）
1. **桌面主控台**（聊天/控制台，最影响观感）优先
2. **手机端待办**（第二）
3. **悬浮球/浮窗**（第三）
4. 后端面板 panel、手机端其余页面（后续，可共用组件）

> 动态 SPA 说明：Vite 构建后仍输出静态文件、由 Go serve，但应用本身是**动态渲染**（路由/组件/状态都在前端运行），不是现在这种"写死 HTML"。

## 三、编码工具（按你最终情况调整）
### 定论：**主力 = Trae CN（继续用）＋ AGNES 3.0 Flash 模型（控成本）**
你的实际情况（全部采纳）：
- Trae CN 国内无对手，你用惯 + **手机版远程操作**（你常不在家）→ 继续当主力 IDE
- **AGNES 3.0 Flash 当主力模型**：DeepSeek 烧钱（白泽已烧近 70），AGNES 3.0 Flash 便宜够用 → 控成本
- Trae CN 的编译/调试/补全保留

### Claude Code / Claw Code 的说明（为什么不用，记录你的顾虑）
| 顾虑 | 情况 | 结论 |
|---|---|---|
| 没有 Claude 会员 | ✅ Claw Code 是开源复刻，**不需要 Claude 会员**，可接国产模型（AGNES/DeepSeek OpenAI 兼容端点） | 技术上可用 |
| 不会用 / 太麻烦 | 你明确不会用 CLI 那套 | 不强迫 |
| 需要手机远程 | CLI 无手机版 | 不适合你的使用场景 |
| 国内可用性 | 开源 CLI 国内可用，但需自己配模型 | 备用项 |
> **结论：你继续 Trae CN + AGNES 3.0 Flash，最符合你的操作习惯和成本。Claw Code 只作为以后"需要批量重写代码"时的可选工具，不强制。**

## 四、成本控制要点（呼应你手头紧）
- 主力模型：**AGNES 3.0 Flash**（便宜）；DeepSeek 降为备用/重活
- 本地能力（语音、截图、键鼠、小模型推理）用 Rust/Go 本地跑，**不烧 token**
- 图/视频生成：按需接 Provider，生成类任务设配额，避免失控烧钱
- 前端 Vue3 全本地运行，零 API 成本

3. **编码**：Trae CN 主力（含手机远程）+ AGNES 3.0 Flash 控成本；Claw Code 备用不强制。
