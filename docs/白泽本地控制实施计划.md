## 1. P0 · 桌面 GUI 竖切（先跑通一条闭环）

**目标**：在记事本/浏览器上完成「截图 → 决策 → 点击 → 回读断言」闭环，成功率 ≥80%，失败必带原因码。

| ID | 任务 | 改哪里 | 验收 |
|---|---|---|---|
| T0.1 | 扩展动作契约：`gui.move/drag/scroll/window/wait/assert`（+`gui.screenshot` 增 `monitor` 参数） | `shared/proto/proto.go`：加常量、加进 `knownActions` | `proto.KnownAction("gui.wait")==true`；其余端无需改 |
| T0.2 | 实现 move/drag/scroll | `desktop/gui_windows.go` 新增 `guiMove`（SetCursorPos）、`guiDrag`（按下-移动-抬起）、`guiScroll`（`mouse_event` WHEEL） | 单测解析参数；真机拖拽窗口/滚动网页各 1 次通过 |
| T0.3 | 实现窗口动作 | 复用 `windowAppAt:158` 思路，新增 `EnumWindows` + `GetWindowRect` + `ShowWindow/SetForegroundWindow` | 能列出窗口、聚焦指定窗口、返回 `hwnd/rect/pid/app` |
| T0.4 | 接线与闸门 | `desktop/device_windows.go`：switch 加分支、`guiActions():545` 收录、`guiGate/guiTargetApp` 覆盖新动作 | 非白名单进程被拒且回 `perm_denied`，不静默 |
| T0.5 | 坐标归一化 | `guiScreenshot` 返回值补 `monitor rect`、`scale`、虚拟屏偏移；新增显示器枚举（现有仅用 `GetSystemMetrics` 虚拟屏） | 模型侧只拿 0–1 坐标；多显示器下点击不偏（现有 2 块虚拟显示适配器） |
| T0.6 | 决策回路 | `agent/internal/tools/` 新增 `desktop_ui.go`：`desktop_observe`（截图）/`desktop_act`（动作），内部 `hub.CreateTaskEx` | 模型能自主完成 3 个任务；每次动作有 `taskId` 可回放 |
| T0.7 | VLM 兜底 | `agent/internal/llm` 增加图片输入调用（provider 需支持 image）；默认 `glm-4.6v` | 截图→返回 JSON 动作，含栏目归因失败时回 `no_target` |
| T0.8 | 安全补强 | `desktop/server.go`：`/api/local/*` 增回环 + `X-Baize-Local` 令牌校验；`gui_windows.go` 加敏感窗口黑名单 | 伪造请求被 403；黑名单窗口自动拒绝 |
| T0.9 | 测试与验收 | 补 `desktop/gui_windows_test.go`（move/scroll/window 参数与坐标换算）；`agent/internal/httpapi/dispatch_test.go` 覆盖 `gui.*` 审批流 | `go test ./...` 绿；手测清单 3 任务 ×10 次 ≥80% |

**先行阻断项**：T0.7 需要智谱 API Key（`autoglm-phone`/`glm-4.6v`）；无 Key 时 T0.6 只能跑 UIA/固定坐标分支。

## 2. P1 · 手机竖切（ADB 主线）

**目标**：真机完成「打开应用 → 搜索 → 点结果」，无 root，失败可人工接管。

| ID | 任务 | 要点 | 验收 |
|---|---|---|---|
| T1.1 | ADB 宿主就位 | Windows 侧装 platform-tools（当前**未装**）；`desktop` 启动时探测 `adb` 并上报 `caps:["android.*"]` | `android.devices` 返回 `serial/model/androidVersion` |
| T1.2 | 设备动作 | 新增 `android.screenshot / tap / swipe / input / key / launch / current / size` | 8 个动作在真机逐条通过 |
| T1.3 | 坐标与输入 | 用 `wm size`/`wm density` 做 0–1 归一化；中文走 ADBKeyboard 广播 | 中文搜索词可输入；折叠/分屏切换后不偏 |
| T1.4 | 决策接入 | `autoglm-phone`（首选）或 `glm-4.6v`（备选）生成动作 JSON；复用 P0 的 observe/act 循环 | 3 任务 ×5 次 ≥60%（允许接管） |
| T1.5 | Take_over 状态机 | 新增 `awaiting_human` 状态：暂停、截图推给用户、恢复后继续 | 登录/验证码场景不硬闯、可续跑 |
| T1.6 | 权限与失败码 | `unauthorized/offline/no_device/secure_page/timeout` 分类回执 | 拔线后回 `offline`，不挂死 |

**前置条件**：一台 Android 测试机（当前无设备连接记录，`adb` 也未安装，**均未核查**）。

## 6. 风险与回滚

| 风险 | 触发 | 处置 |
|---|---|---|
| DPI 改动导致点击偏移 | 一旦声明 Per-Monitor V2 | 单独特性开关；保留"虚拟坐标"分支，用截图尺寸做校验 |
| 虚拟显示适配器干扰截图 | GameViewer/MuMu 适配器 | 强制按 monitor 枚举，禁止只取主屏 |
| 高完整性窗口注入失败（UIPI） | 管理员程序/UAC | 预检 `GetLastError`+目标进程完整性级别，提前报 `blocked` |
| 审批被绕过 | `Hub.Dispatch` 硬编码 `agent-approval-gate` | P2 收敛为单一闸门；临时用审计日志兜底 |
| 公开仓暴露执行器 | `baize-public` 镜像 | 公开构建剔除执行器与凭据，默认关闭 |

回滚：每阶段独立开关（`gui.gate`、`android.enabled`、`vlm.fallback`），出问题只关闭对应开关，不回滚整包。
