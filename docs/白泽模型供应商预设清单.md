## 五、3D 生成能力（你要的，单独列出）
| 能力 | 方案 | 说明 |
|---|---|---|
| 文生3D / 图生3D | **腾讯混元生3D API** | 国内 `ai3d.tencentcloudapi.com`，OpenAI 兼容 `https://api.ai3d.cloud.tencent.com`；Text/Image → 3D，输出 **OBJ/GLB**；并发默认 1-3 任务 |
| 3D 修改/精修 | **桌面 Blender 控制** | 白泽电脑控制（GUI/命令）直接驱动本机 Blender 改模型 |
> 这样白泽能做：2D 画面（文生图/图生图）+ 3D 模型（混元3D 生成 + Blender 精修），覆盖你要的"2D+3D"。
