CORE FEATURES

核心能力

从设备中枢到记忆星图，从插件市场到外部 Agent——白泽把智能体需要的一切都做全了。

跨端调度

NAS 后端统一编排，把任务路由到具备对应能力的设备——手机布置需要电脑能力会自动转派桌面执行，反之亦然。

长期记忆

混合检索（图谱 + 向量 + 关键词 + 时效性）+ 记忆树自动召回三闸门，还有笔记星图——双向链接与语义自动连边。

安全审批

危险动作（删除 / 提权 / 发消息 / 改权限）强制人工确认，审批闸门支持「本次放行 / 永远放行」记忆，超时自动拒绝。

插件市场

技能 + MCP 热插拔，内置官方源离线可用，也支持任意静态托管当源。板块 / 阶段 / 分类三维货架，一键安装。

多频道接入

Webhook / QQ OneBot / 飞书 / 钉钉 Stream / 腾讯元宝 / 个人微信——六个频道类型，和白泽在你用的地方对话。

定时任务

Cron 表达式 + 一句目标，后台自动触发。内置心跳、每日简报、定时巡检等技能开箱即用。

QUICK START

一条命令部署

后端用 NAS 部署脚本，桌面端和手机端各一条构建命令。

# 1. 在仓库根建 deploy.local.env（模板见 deploy.local.env.example）
#    填 NAS 地址 / 用户名 / 密码 / 配对令牌

# 2. 一条命令：构建 → 上传 → NAS 打镜像 → 起容器 → 健康检查
powershell -ExecutionPolicy Bypass -File tools\deploy-nas.ps1

# 后端启动后默认监听 http://:8787
# 首次启动会自动建 admin 账号，随机口令写 <数据>/admin-password.txt
# 1. 构建（纯 ASCII 脚本，无 cgo / 无 Rust）
powershell -ExecutionPolicy Bypass -File desktop\build.ps1

# 2. 首次运行，指定后端地址和配对令牌
desktop\bin\baize-desktop.exe --server http://<NAS>:8787 --token <令牌>

# 之后直接双击 exe 即可（配置保存在 %APPDATA%\白泽\desktop.json）

# 3. 要打安装包
powershell -ExecutionPolicy Bypass -File desktop\build-installer.ps1
# → bin\baize-desktop-setup-0.5.27.exe
# 两步合一：先交叉编译 Go 内核（arm64），再打 APK
powershell -ExecutionPolicy Bypass -File android-app\build.ps1

# 产物：android-app\bz-todo-v0.10.16.apk

# 安装到设备（用 adb）
adb connect <手机IP>:5555
adb install -r android-app\bz-todo-v0.10.16.apk

# ⚠️ 三星等激进 ROM：必须在系统设置里手动允许「自启动」
#    设置 → 应用 → 白泽 → 允许自启动
