# 需求 · 白泽内置虚拟桌面（虚拟显示器）功能

> 来源：用户口述（2026-11-22 00:29，会话 m01961）｜证据等级：口述｜状态：**只登记，未实现**

## 用户原话要点
- 「那个虚拟桌面，我要的是白泽直接内置这个功能，装好白泽可以直接用，懂吗现在不用做了记着就行」。

## 需求描述
- 目标：把「虚拟桌面 / 虚拟显示器」能力**内置进白泽产品本身**，用户装好白泽即可直接使用，无需外挂第三方工具、无需额外手动配置。
- 用途：白泽自动化（尤其手机端后端直控、桌面端自动化窗口）在独立虚拟屏上运行，做到「用户主屏随便用、自动化只在虚拟屏跑、互不干扰」。

## 与当前现状的差别（重要）
- 现状（临时方案，仅本机验证用）：外挂 ParsecVDisplay（Parsec Virtual Display Adapter）加一块 1920x1080@60Hz 虚拟屏，需手动 launch_app 起进程 + 点 xAdd 加屏、用完杀进程关屏；驱动零自启，全靠人管。
- 目标态（本需求）：白泽安装即自带虚拟显示器能力，自动创建/管理/回收虚拟屏，用户无感知、开箱即用。这是产品功能，不是本机脚本或外挂依赖。

## 验收标准（助手自定，待用户确认）
1. 安装白泽后，无需安装 ParsecVDisplay 等任何第三方虚拟屏软件即可启用虚拟桌面。
2. 白泽可在设置/界面里一键开关虚拟桌面；开启后出现独立 1920x1080@60Hz 屏幕，自动化窗口默认落该屏。
3. 关闭/退出白泽时自动回收虚拟屏，不留残留显示设备。
4. 用户主屏全程不受干扰（窗口不抢焦点、光标不落主屏）。
5. Windows 端为主（当前虚拟屏方案是 Windows 平台）；其他平台按需扩展。

## 实现待解（调研方向，非本轮任务）
-  Windows 虚拟显示器驱动方案：微软 Indirect Display Driver（IDD）/ WDDM，或自签名驱动；需处理驱动签名与安装权限。
- 「虚拟桌面」（Win11 多桌面）与「虚拟显示器」（多一块屏）是两回事：用户此前口中的「虚拟桌面」多指后者（独立屏幕），本需求按虚拟显示器理解；若确指 Win11 多桌面需再确认（其 COM 接口 IVirtualDesktopManagerInternal 未公开）。
- 与现有屏幕控制铁律（~/.dsh/AGENTS.md）的关系：内置后应替代外挂 Parsec 流程。
